SIDE-001 · TOOL-BASED DESIGN STUDY

뭐먹지?

메뉴를 빠르게 결정하는 작은 슬롯머신 웹앱. 색채의 맥락과 핵심 오브젝트의 비율, 화면 정렬, 작은 상호작용이 디자인의 인상을 어떻게 바꾸는지 살펴본 사례입니다.

메뉴 추천 실행하기 ↗ 앱 소스코드 비교·교훈 전문

현재 채택한 디자인

아이보리·오렌지·차콜의 따뜻한 팔레트, 중앙 집중형 컨테이너, 슬롯과 설정 패널의 조화로운 비율을 유지합니다. 데스크톱에서는 패널의 하단을 정렬하고, 사용법 토글은 +가 ×로 회전하며 열림·닫힘 애니메이션을 제공합니다.

관찰과 배운 점

  • 주인공인 슬롯머신과 배경 색채의 관계가 개별 색상의 선명함보다 중요했습니다.
  • 넓은 화면을 무조건 채우거나 왼쪽 정렬하는 대신, 작은 도구의 작업 규모에 맞춰 중앙 배치를 검토했습니다.
  • 사용자는 슬롯과 설정의 상대 비율은 긍정하면서 차가운 배경 실험은 선호하지 않았습니다.
  • 다른 요소를 모두 바꾸기보다 하단 기준선과 설명창 모션처럼 작게 마감하는 개선도 중요했습니다.

운영 원칙

실행 가능한 최신 앱은 별도 menu-roulette 저장소의 main 하나에서 관리합니다. 이 페이지는 연구 요약과 이동 경로만 제공합니다. 개인의 취향과 실험에서 얻은 판단을 범용 디자인 지침의 의무 규칙으로 자동 승격하지 않습니다.

이 사례는 제작자 피드백을 정리한 정성적 기록이며, 일반 사용자 대상 실험이나 성능 개선을 증명하는 자료는 아닙니다.
