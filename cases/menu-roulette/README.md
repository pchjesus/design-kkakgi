## 운영과 소스의 경계

- 이 폴더는 학습한 디자인 판단과 사용자 평가의 기록이다. 코드 미러나 별도 배포 브랜치를 만들지 않는다.
- 현재 앱의 단일 실행 원본은 `pchjesus/menu-roulette`의 `main`이다. 디자인 깎기의 카드와 사례 페이지는 그 정식 URL로 연결한다.
- 메뉴 추천 기능과 버전 업데이트는 해당 앱 저장소에서 계속 관리한다.
- 이전 색채 실험안은 현재 디자인으로 유지하지 않으며, 실패·부분 성공을 문서로 보존한다.
- 지침 v1.2를 정식 변경하는 것은 별도 사용자 승인 사항이다.

## 사건 요약

1. 청백색 실험은 오렌지 슬롯 및 식품 맥락과의 조화 부족으로 비선호.
2. 실험안의 슬롯/설정 비율은 선호되어 보존.
3. 기존 따뜻한 색감과 중앙 집중형 배치를 결합한 Warm-centered 채택.
4. 패널 하단 정렬과 사용법 아코디언 모션을 수정하여 승인.
5. 최종 코드만 메뉴 앱 `main`에 정리하고 이 사례는 운영 히스토리/교훈을 남김.
