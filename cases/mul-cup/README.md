# MUL. 물컵 홍보 사이트 — 버전별 전체 프로젝트 아카이브

이 ZIP은 같은 **가상 브랜드 MUL.**의 사이트 제작·개선 실험을 **초본부터 Refined까지 5단계**로 정리한 백업이다. 각 버전의 실행 HTML, 당시 기록/테스트, 미리보기 및 피드백을 보존했으며, **이전 파일을 최신판으로 덮어쓰지 않았다**.

## 먼저 볼 파일

- `versions/01_v1.1_Initial/site/index.html`: 가장 처음 만든 v1.1 홍보 사이트
- `versions/02_v1.1_Animated/site/index.html`: 기본 애니메이션 추가 버전
- `versions/03_v1.2_Catalog/site/index.html`: v1.2 가이드 적용, 구매 UI를 전면화한 비교안
- `versions/04_v1.2_Rework/site/index.html`: 홍보·브랜드 경험을 중심으로 재설계한 버전
- `versions/05_v1.2_Refined/site/index.html`: 최신 개선본(드래그 회전 및 디테일 개선)
- `HISTORY_AND_FEEDBACK.md`: 각 단계의 사용자 요구·관찰·평가·적용 결과
- `USER_FEEDBACK_ORIGINAL.md`: 대화에 기록된 중요한 사용자 평가 원문
- `COMPARISON_AND_LESSONS.md`: 개선과 퇴보, 원인 구분 및 지침 개선 후보
- `FILE_MANIFEST_SHA256.tsv`: 이 아카이브 내부 파일별 경로와 해시

## 보존 원칙과 파일 출처

1. 01·02는 **당시 배포 ZIP에서 실행 파일·README·검증 기록을 추출**하여 스냅샷을 확보했다. `/mul-cup-site/index.html`은 이후 애니메이션 버전으로 덮어써졌으므로 초기 버전의 출처로 사용하지 않았다.
2. 03·04·05는 당시 내보낸 **최종 HTML을 우선** `site/index.html`로 넣었다. 원래 작업 폴더의 중간 소스·테스트·이미지는 별도로 보존했다.
3. `original_release_archives/`에는 이전에 전달한 5개 원본 ZIP을 **바이트 그대로** 보존했다. 버전 디렉터리에 중복된 파일이 있는 것은 추적과 즉시 실행을 쉽게 하기 위함이다.
4. `reference_guidelines/`에는 실험에 이용한 원본 v1.1, v1.2, 빠른 실행 카드를 포함했다. 지침 원문은 수정하지 않았다.
5. 일부 미리보기는 실행 HTML과 독립적으로 촬영한 정적 스크린샷이다. 동작 검증을 대체하지 않는다.
6. `misc_review_crops/`는 분석용 잘라낸 이미지로, 사이트 공식 화면이 아니다.

## 검증 및 한계

기존 기록에서 Chromium 자동화로 확인한 조작만 해당 버전의 `PASS`로 유지했다. **현재 ZIP 제작은 브라우저 기능의 재검증이 아니라 파일 수집·보존·무결성 검사**이다. 구버전의 실제 재방문 저장 복원, 전체 접근성, 모바일 실기기, 사용자 대상 사용성 실험은 기존 기록대로 `NOT RUN`이며, 미실행을 `PASS`로 바꾸지 않았다.

최신 검증의 상세 내용은 각 버전 `docs/`와 `tests/`에서 확인할 수 있다. 장바구니 보존 키는 주요 버전에서 `mul-demo-bag-v1`로 유지되었다.

## 저작 및 배포

MUL.은 본 실험을 위한 가상 브랜드이며, 사이트는 상용 브랜드·실판매 웹사이트가 아니다. 원본 아카이브는 분석/재현을 위한 비교 자료다. GitHub 업로드나 외부 배포는 수행하지 않았다.
