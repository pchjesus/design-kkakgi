컵의 무게감은 어디서 느껴질까?

승인된 MUL. E8의 실제 SVG 대체 그래픽과 최종 CSS 착지 타이밍을 복제한 독립 학습 실험이야. 880ms 전체 시간·착지 시점·가속도는 그대로 두고, 반동 높이 한 가지만 비교해 봐. 본편 3D·구매 기능은 건드리지 않았어.

코드 읽기 연습: 딱 한 줄만 바꾼다면?

원본 E8의 최종 착지 효과는 54% 시점에 닿고 → 76% 시점에 반동 → 100%에 정착하는 구조야. 여기에선 76%의 이동 거리만 변수로 뺐어.

/* E8 원본 — 76%에서 19px 위로 */
76% { transform: translate3d(0, -19px, 0) rotate(16deg); }

/* Motion Lab — 두 안을 하나의 CSS로 비교 */
76% { transform: translate3d(0, var(--bounce-height), 0) rotate(16deg); }

/* A는 -19px / B는 -10px */

이해하면 좋은 개념 세 가지

HTML은 컵과 재생 버튼의 자리, CSS는 착지 동작과 색·크기, JavaScript는 버튼을 누르면 애니메이션을 다시 시작하는 역할이야.

이제 네가 직접 B의 높이를 바꿔보면서 “몇 px가 더 단단하고 자연스럽게 보이는가?”를 비교하면 돼. 다음 실험에서는 높이가 아닌 전체 시간을 바꿔볼 수 있어.

실험 범위와 주의점

이 페이지는 원본의 SVG 대체 그래픽을 사용한 착지 모션 비교기야. 실제 3D WebGL 렌더링이나 구매 화면은 포함하지 않아. 움직임 감소 설정을 켜면 애니메이션을 실행하지 않으며, 실제 3D 본편의 동작 검증으로 간주하지 않아.
