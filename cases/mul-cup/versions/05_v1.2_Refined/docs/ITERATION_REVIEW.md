## 1. 이번 피드백에서 확인한 강점 — 반드시 보존

1. 첫 화면의 정보 과잉을 피하고 컵·브랜드 인상이 먼저 보이는 구성.
2. 「조금 더 가볍게.」 아래의 가는 곡선 밑줄: 은근한 강조가 좋으므로 존재와 형태는 유지.
3. `컵의 색 살펴보기`의 짧은 hover 반응.
4. 두 번째 섹션에서 좌측 여백을 크게 남기고 오른쪽으로 내용을 정리하는 구조.
5. 섹션별 미세한 배경색 차이, 구분선·장식의 절제.
6. 소재 특징을 3개로 나눈 구조와 적절한 정보 밀도.
7. 디자인 노트의 비대칭 배치, 반전된 컵의 각도, 하단 반원 그래픽.
8. 구매 정보가 뒤로 물러난 브랜드 탐색 중심의 흐름.

## 2. 이번 수정에 반영한 항목

| 피드백 | 변경 | 유의점 |
|---|---|---|
| 강조선의 색이 조금 어울리지 않음 | 색을 부드러운 아쿠아 계열로 재설정하고 곡선 형태 유지 | 더 과하게 강조하지 않음 |
| 컵을 누르고 드래그하여 돌려보고 싶음 | 색상 비교 화면에 오프라인 Canvas 기반 회전 미리보기 구현. 마우스·터치 수평 드래그, 키보드 좌우 화살표, Home/초기화 지원 | **실제 실물의 3D 스캔은 아님**. 축대칭 컵이므로 로고와 하이라이트의 위치 변화가 회전감을 보조하는 2.5D 표현 |
| 색상 비교 배경이 흰색이면 좋겠음 | 컵의 회전 미리보기 배경을 흰색으로 고정. 색상만 변경 | 주변 섹션은 연한 청백색을 유지해 위계 보존 |
| 설명 끝에 한 글자만 줄바꿈됨 | 세 가지 설명을 짧고 완결된 문장으로 재작성하고 균형 줄바꿈 적용 | 글꼴·언어·화면 폭에서 줄 수가 완전히 동일하다고 보장하지 않음 |
| 「오늘도, 물 한 잔」 영역이 높고 색 탐색 중복됨 | 하단 섹션을 짧은 구분 띠로 축소, 중복 컬러 CTA 제거 | 상단 내비게이션 및 실제 색상 선택 영역은 그대로 유지 |

## 3. 디자인 판단

- 의도: 기존 디자인의 평온함을 유지하며 실제 제품 탐색의 재미를 보강한다.
- 사용자의 선호를 새 필수 규칙으로 일반화하지 않는다. 특히 얇은 구분 띠·아쿠아 밑줄은 **이번 브랜드의 선택**이다.
- ‘흰 배경 고정’은 컬러별 제품 비교의 기준 환경을 통제한다는 목적을 가진다.
- 컵 회전은 정적인 단일 이미지보다 자세히 살펴보는 조작 가능성을 높이지만, **실물 검증용 3D 모델이라고 주장해서는 안 된다.**
- 구매 패널·가격·색상·장바구니·FAQ의 정보 기능은 보존한다.

## 5. 다음 점검 시 고려할 한계

- 회전 미리보기는 원통형 컵을 투영한 Canvas 도식이다. 깊이 변화·내부 굴절·유리 물성은 정확한 3D 렌더링과 다르다.
- 새로운 그래픽이 기존 SVG 일러스트와 조금 다른 인상을 주기 때문에 이미지 연속성을 실제 사용자에게 확인해볼 가치가 있다.
- 줄바꿈은 기본 시스템 글꼴의 차이·뷰포트·브라우저 설정에 영향을 받는다. 지나치게 통제하려고 고정 줄바꿈을 넣으면 모바일에서 역효과가 생길 수 있다.
- 실제 제품 사양과 가격은 가상 예시이며 판매/결제가 진행되지 않는다.

## 6. 지침 개정 여부

- **v1.2 지침은 수정하지 않음.** 이 사례는 구현의 국소적 정교화이다.
