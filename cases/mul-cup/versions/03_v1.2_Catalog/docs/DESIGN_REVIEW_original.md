# MUL. 데일리 글라스 — v1.2 디자인 적용 및 검증 기록

기준: Universal Visual Design & UI/UX Guidelines v1.2 (DRAFT, 2026-10-15) / 이전 구현: v1.1 기반 animated demo.

## 설계 가설

첫 화면의 시선을 감성 문구·연녹색 배경 대신 **컵과 즉시 조작할 수 있는 제품 정보**로 옮기면, 홍보 사이트의 목적을 더 신속히 이해할 수 있을 것이다. 성공을 판단하려면 첫 화면의 제품명·제품 시각 자료·가격·색상·장바구니 조작의 존재, 기존 기능 유지, 작은 화면 접근성을 관찰해야 한다. 실제 사용자 이해도 증가는 사용성 평가 전까지 단정하지 않는다.

## 아트 디렉션 결정

- 사용자/목적: 물컵을 처음 보는 방문자 / 제품 형태와 컬러를 살펴보고 시연용 장바구니에 담기.
- 화면 유형: **제품 우선형 인터랙티브 카탈로그**. 브랜드 소개 섹션은 후순위.
- 시각 언어: 유리의 투명감과 물의 시원함을 연상시키는 블루, 화이트, 딥 네이비; 색상 변경 시 전체 제품 배경 전환. 기존 연녹색/크림색 대신 명확한 대비로 전환.
- 서체: 한글은 Noto Sans CJK KR 중심, 폴백 Apple SD Gothic Neo / Malgun Gothic; 영문·숫자는 Arial과 시스템 폴백. 실제 Chromium 렌더링에서 Noto Sans CJK KR(한글), Arimo(영문)를 확인했다. 별도 폰트 파일/외부 웹폰트 사용하지 않음.
- 의도적으로 배제: 추상 감성 슬로건·과잉 영어 라벨·둥근 카드/궤도 장식·무한 부유 모션.
- 시각 자산: 이전 데모의 독립 제작 SVG 컵 그림을 이어 사용. 상업 제품 사진이 아니며, 페이지의 '시연' 공지가 이를 분리한다.

## 실행 검증

Chromium 헤드리스 엔진에서 HTML을 직접 주입해 검사함. 해당 실행 환경은 로컬 파일/로컬 서버 브라우저 내비게이션이 제한되어 있었음. 저장 복원은 인메모리 Storage 대체 구현을 통해 HTML 재주입 후 검증했으며, **실제 origin 기반 로컬스토리지 + 새로고침 검증을 완료했다는 의미는 아님**.

| 검증 항목 | 상태 | 근거 |
|---|---|---|
| 1440·1024·790·390·360·320px 가로 넘침 | PASS | 6개 뷰포트에서 `scrollWidth - clientWidth = 0` |
| 주요 제품 및 상태 렌더링 | PASS | 브라우저 DOM 검사와 스크린샷 수집 |
| 색상 변경 및 선택 aria-pressed | PASS | 1440·390·320px 클릭 테스트 |
| 수량 증가, 담기, 합계, 삭제 | PASS | 클릭/가격 검증(2개 = ₩39,600) |
| 장바구니 ESC 닫기, 모바일 메뉴, FAQ | PASS | 1440·390·320px에서 필요한 항목 실행 |
| 저장된 장바구니 재렌더링 | PASS (모의 저장소) | 인메모리 저장소 활용한 document 재주입 검증 |
| 실제 브라우저 새로고침/재방문 보존 | NOT RUN | 브라우저 로컬 내비게이션이 관리 환경에서 차단 |
| 움직임 감소 환경 | PASS | `prefers-reduced-motion: reduce`에서 컵 애니메이션 없음 |
| 텍스트 확대 200%의 전체 가로 넘침 | PASS (모의 확대) | html root 200% 적용 시 390px viewport 가로 넘침 0; 실제 브라우저 zoom과 별개 |
| 실제 기기와 스크린 리더 전체 접근성 | NOT RUN | 수동 기기 시험 및 전문 접근성 인증 없음 |
| 객관적 사용자 사용성 개선 | NOT RUN | 참여자 기반 테스트 없음 |
| 기존 외부 서버/계정/결제 | N/A | 가상 쇼케이스, 외부 연동 없음 |

## 사용 방법

`index.html` 파일을 일반 브라우저에서 직접 연다. JavaScript 포함 단일 파일이며 별도 빌드/설치/외부 자산 요청이 필요 없다. 이전 v1.1 파일은 비교용으로 함께 보관했다. 모든 용량/가격/제품 속성은 실제 제조사가 검증한 사양이 아닌 콘셉트용 데이터이다.
