# 브랜드 경험 재설계 (가이드 v1.2 유지)

- 실행: `site/index.html` 브라우저 열기
- 스냅샷: 브랜드 소개 우선, 구매 패널 분리, 고정 배경 컬러 비교
- 당시 대표 사용자 메시지: > 좋아 아까보다 훨씬 자연스러운 색감과 이미지야.
- 판단/후속: 첫 화면/여백/모션/섹션 디테일 호평; 드래그 회전·흰 배경·문장·하단 개선 요청.
- 세부 원문: `../../USER_FEEDBACK_ORIGINAL.md`
- 전체 연혁/비교: `../../HISTORY_AND_FEEDBACK.md`, `../../COMPARISON_AND_LESSONS.md`
- 원본 배포 ZIP: `../../original_release_archives/`

`docs/`는 당시에 작성한 설명 및 디자인·검증 기록, `tests/`는 당시 검사 자료, `previews/`는 화면 확인용 이미지다. 해당되지 않는 폴더가 있을 수 있다. 실제 검증 상태는 원본 문서에서 확인한다.
