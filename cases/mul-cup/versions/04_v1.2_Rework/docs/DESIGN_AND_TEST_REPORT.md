**상태:** v1.2 범용 지침 적용 견본. 새 범용 버전(v1.3)이 아님. 2026-10-16.

## 1. 자료·버전

- 기준 지침: `Universal_Visual_Design_UI_UX_Guidelines_v1.2.md` (DRAFT).
- 이전 결과물: `MUL_Cup_v1.2.html` (제품 카탈로그형), `MUL_previous_v1.1.html`.
- 신규 결과물: `index.html` (완전 독립 실행형 HTML), 자체 제작 SVG 컵 삽입.

- 저작·사실 범위: MUL.은 가상 브랜드이며 컵·용량 380mL·가격 ₩19,800은 시연 자료다. 실제 검증된 제품 정보나 판매 서비스가 아니다.

## 2. 의도와 아트 디렉션

- 사용자/목적: 처음 방문한 사람이 물컵과 브랜드의 인상을 느끼고 제품 색을 살펴본 뒤 필요하면 구매 정보를 찾도록 돕는다.
- 첫 화면 유형: **제품+브랜드 경험 중심형**, 쇼핑몰식 주문 폼 노출은 회피.
- 서체: `NanumSquareRound`를 우선 사용하는 한글 둥근 산세리프 계열과 시스템 폴백. 영문 워드마크는 `Comfortaa` 계열 폴백. 라이선스 제한을 피하기 위해 폰트 파일을 배포하지 않음. 컴퓨터에서 글꼴이 없으면 대체 글꼴이 표시됨.
- 팔레트: 물의 투명감과 어울리는 저채도 아이스블루·흰색 바탕, 선명한 푸른색은 CTA·작은 마크·일부 헤드라인에 국한. 원색 사용 자체를 회피하지 않고 **비율을 조절**.
- 모션: 첫 진입하는 컵의 미세 움직임, 스크롤 등장, 색상 전환, 패널 이동. 시스템 움직임 감소 설정에서 동작 중지.
- 배제한 관습: 과도한 가격 전면화, 광범위한 코발트 배경, 제품 색에 연동되는 배경색, 딱딱한 대형 고딕, 의미 없는 장식용 영문 라벨.

## 5. 반응형·애니메이션 검증

- Chromium 브라우저에서 직접 HTML을 렌더링(`set_content`)하고 mock Storage 사용.
- 뷰포트 `1440 / 1024 / 790 / 700 / 390 / 360 / 320px`에서 문서 수평 넘침 **0px (PASS)**.
- `1440 / 390 / 320px`에서 색상 전환, 패널 접근, 가격/수량/담기/합계/삭제, ESC, FAQ, 모바일 메뉴를 실행했고 모두 **PASS**.
- 글자 200% 확대를 루트 폰트 크기로 모의 적용한 390px 환경에서 가로 넘침 **0px (PASS, 모의 확대)**. 초기 초안에 있었던 제목 `nowrap` 잘림을 제거한 뒤 재검증. 실제 브라우저 200% 줌 전체 검증은 **NOT RUN**.
- `prefers-reduced-motion: reduce`에서 컵 애니메이션 계산값 `none` **PASS**.
- JavaScript 오류 0건 **PASS**.
- 클리어/앰버/스모크 SVG 컵 렌더링은 색상 레이어를 보완하여 뚜렷하게 구분. 작업 초기에 변하지 않던 오류를 수정하고 다시 캡처함.
- 스크린리더, 실제 모바일 터치·사용성, 구매 탐색 속도, 색상 인지 정확도 **NOT RUN**.

## 6. 강점과 미해결 위험

### 유지·개선한 강점

1. 기존 v1.2의 정보 위계는 포기하지 않고 제품 탐색 흐름에 맞춰 이동했다.
2. 색상을 비교하는 화면의 배경을 고정해 일관된 비교 조건을 확보했다.
3. 가격과 주문 수량은 언제나 명시적인 `구매 정보` 버튼으로 열 수 있다.
4. 색상 상태와 장바구니 상태 및 기존 저장 키를 유지했다.
5. 미세 모션의 분위기 기능과 상태 전환 기능을 구분했다.

### 아쉬움·회귀 위험

1. 구매 기능이 패널 안으로 이동했으므로 **목적이 즉시 구매인 방문자**에게는 클릭이 추가된다. 실제 이탈/불편 여부 미검증.
2. SVG 콘셉트 이미지는 실물 사진의 재질 표현을 완전히 대체하지 못한다. 컵은 일러스트라고 표시했다.
3. `NanumSquareRound` 등의 로컬 서체가 없는 운영체제에서 폴백으로 미감이 달라질 수 있다. Windows/macOS 실기기 확인 필요.
4. 차분한 색과 감성 카피가 아직도 일반적인 생활용품 광고로 보일 수 있다. 사용자 선호도 검증 전에는 '완벽한 브랜드 경험'이라고 단정하지 않는다.
5. 화면 테스트 일부는 mock Storage에 기반하므로 실제 `file://`/호스팅 환경의 새로고침 복원이 같은 결과를 낼지 확인이 필요하다.

## 7. 결론과 다음 검증

- **PASS:** 문서/소스 기반 구조 수정, 제품색 비교 조건, 대상 뷰포트·핵심 기능의 브라우저 동작, 시스템 모션 감소.
- **NOT RUN:** 실제 사용자 평가, 클립보드 전체 환경, 실제 모바일/스크린리더, 호스팅 저장/재방문, 실물 제품 정보 검증.
- **유지할 장점:** v1.2의 명료한 정보 구조, 선택·장바구니 피드백 및 복구 접근.
- **권고:** 같은 콘텐츠/기능의 두 버전을 블라인드 평가하여 `처음 5초 브랜드 인식`, `색상 비교 오류`, `구매 정보 발견성`, `브랜드 호감도`, `조작 완료 여부`를 별개로 기록. 표본이 적으면 경향으로만 해석.
- **지침 변경:** 없음. v1.2는 실험 동안 고정.
