# MUL. — 물컵 홍보 랜딩 페이지

이 프로젝트는 `Universal Visual Design & UI/UX Guidelines v1.1`에 맞춘 독립적인 데일리 글라스 홍보 페이지 **디자인 데모**입니다.

## 실행 방법

`index.html` 파일을 크롬/엣지 등 브라우저로 직접 열면 됩니다. HTML/CSS/JavaScript가 모두 한 파일에 포함되어 있습니다. 네트워크 요청 없이 시스템 글꼴을 사용합니다.

## 사용 기능

- 브랜드/제품 소개, 제품 선택 영역으로 이동, 모바일 탐색 메뉴
- 3가지 컬러 미리보기(클리어/앰버/스모크)
- 1~10개 수량 변경
- 데모 장바구니 담기/삭제, 합계 표시, 브라우저 로컬 저장
- 옵션/장바구니 목록 클립보드 복사
- FAQ 펼침/접힘
- 키보드 초점 표시, 장바구니 다이얼로그 포커스 순환/ESC 닫기, 움직임 감소 설정 대응, 320px 반응형 스타일

## 중요 안내

제품명, 용량, 소재 표기, 가격 등은 콘셉트용 가상 정보입니다. 판매, 회원가입, 결제, 서버 저장 기능은 없습니다. 제품 렌더링은 외부 사진 없이 SVG로 직접 구성한 일러스트입니다.

## 검증 및 디자인 접근

- 목적 명확성 → 첫 화면에 제품 비주얼과 1차 행동 제시
- Rams/Braun 참조 → 제한된 강조색, 통일된 정렬·간격, 기능 위주의 선택 UI
- 읽기 흐름 참조 → Hero → 이유/특징 → 시각적 상세 → 제품 선택 → FAQ
- 반응형, 색상 외 텍스트 레이블, 키보드, 피드백, reduced motion 적용
- 실판매 사이트가 아닌 관계로 구매/결제 가능성을 암시하지 않음

실제 기기에서의 모든 접근성 기준 통과/사용성 검증을 의미하지 않으며, 검증 범위는 별도로 기록해야 합니다.
