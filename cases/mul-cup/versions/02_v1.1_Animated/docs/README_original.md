# MUL. — 물컵 홍보 사이트 / Motion Edition

첨부된 `Universal Visual Design & UI/UX Guidelines v1.1`을 참조해 만든 가상 제품 소개 웹페이지입니다.

## 실행

- `index.html`을 Chrome 또는 Edge로 직접 열면 됩니다.
- 별도 빌드, 서버, 라이브러리, 인터넷 연결이 필요하지 않습니다.
- 단일 HTML에 CSS, SVG 컵 일러스트, JavaScript를 모두 포함했습니다.

## 추가한 애니메이션

1. 첫 화면 카피가 순서대로 나타나는 진입 모션.
2. 컵의 느린 상하 이동과 배경 링의 1회 등장 효과.
3. 스크롤 진입 시 섹션들이 순차적으로 나타나는 효과(IntersectionObserver).
4. 컵 색상 변경 시 짧은 제품 미리보기 전환.
5. 장바구니 담기 시 카운트 피드백, 모바일 메뉴/FAQ의 미세 전환.

**접근성:** 운영체제의 `prefers-reduced-motion: reduce`에서 애니메이션을 비활성화합니다. JavaScript/IntersectionObserver가 지원되지 않으면 콘텐츠는 숨기지 않고 표시됩니다. 인터랙션 상태는 색상뿐 아니라 텍스트/수량/레이블로도 전달됩니다.

## 기본 기능 유지

클리어/앰버/스모크 컬러 선택, 수량 조절, 데모 장바구니 담기/삭제/합계, 로컬 저장 시도, 복사, 메뉴, FAQ, 키보드 접근, 모바일 레이아웃.

## 테스트 상태

**PASS:** Chromium 자동 테스트로 1440/390/320px의 색상·수량·장바구니·메뉴·FAQ·가로 넘침·런타임 오류 0개 확인. 움직임 감소 환경에서 애니메이션 비활성 확인.

**NOT RUN:** 브라우저 저장/재방문 확인(현재 테스트 환경의 탐색 제한), 실제 모바일 기기, WCAG 전체 대비·200% 확대 감사 및 실제 사용자 사용성 테스트. 저장 동작은 코드상 기존 구조를 유지했습니다.

## 데모 성격

브랜드명, 컵의 용량/소재/가격은 테스트용 가상 정보입니다. 실제 결제 기능은 없습니다.
