Need to know

자주 묻는 질문

실제 판매 제품이 아닌 디자인 시연 페이지입니다. 이용 전에 아래 내용을 확인해 주세요.

이 컵을 실제로 구매할 수 있나요?

현재는 UI/UX 디자인 가이드 적용을 확인하기 위한 가상 브랜드 쇼케이스입니다. 장바구니와 색상 선택은 작동하지만 주문과 결제는 진행되지 않습니다.

색상과 용량은 실제 상품 정보인가요?

아니요. 클리어·앰버·스모크의 색상 구성, 380 mL 용량 및 가격은 디자인 시연을 위해 설정한 예시입니다. 제조사에서 검증한 사양이 아닙니다.

담아둔 제품은 어디에 저장되나요?

선택한 구성은 사용 중인 브라우저의 로컬 저장소에만 보관합니다. 별도의 서버 전송이나 회원 가입이 없으며, 브라우저 데이터 삭제 시 사라질 수 있습니다.

디자인은 어떤 원칙을 따랐나요?

명료한 정보 위계, 절제된 시각 언어, 읽기 쉬운 타이포그래피, 반응형 화면, 조작 피드백 등 Universal Visual Design & UI/UX Guidelines v1.1을 적용했습니다. 외부 브랜드의 제품 외형을 복제하지 않은 독립 콘셉트입니다.
