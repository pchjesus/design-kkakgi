# 디자인 지침 검증을 위한 비교 결론 및 개정 보류 항목

## 개선·퇴보 분리

| 평가 축 | v1.1 Initial/Animated | v1.2 Catalog | v1.2 Rework/Refined |
|---|---|---|---|
| 제품의 목적 전달 | 감성 카피가 선행 | 제품 정보 명확 | 제품을 먼저 보여주되 과도한 판매 UI 제거 |
| 브랜드 감성 | 부드럽지만 상투적 가능성 | 딱딱하고 압박적이라는 사용자 평가 | 더 자연스럽고 안정적이라는 사용자 평가 |
| 색채 | 크림/세이지에 편중 | 강렬한 파랑이 시선 독점 | 청백색+절제된 강조, 색상 비교는 흰 배경 |
| 서체 | 감성은 있으나 한글-영문 폴백 검토 필요 | 기술적 명료성 향상, 정서 적합성 퇴보 | 둥근 느낌의 가벼운 서체, 환경별 폴백 숙제 |
| 조작 | 색상·구매 기능 하단 | 구매 기능 즉각 노출 | 기능 보존·구매 별도 패널로 단계적 접근 |
| 컵 색상 비교 | 색상 교체 가능 | **배경도 변경**되는 부작용 | 고정 배경 + 컵색만 변경, Refined에서 드래그 회전 |
| 모션 | 부유 및 스크롤 애니메이션 | 기능 피드백 중심 | 브랜드 분위기 + 직접 조작형 탐색 |
| 검증 | 시연 기능 자동검사 위주 | 반응형·기능 일부 자동검사 | 추가 회전·저장 fixture·200% 모의 확대 검사 |

## 원인 분류

1. **지침 해석 / 과제 정의:** 물컵을 '홍보'한다는 목표를 즉시 '판매'로 좁혀 판단한 오류가 Catalog에 반영됨.
2. **구현 미준수:** v1.2에서도 영문 장식 문구/일부 작은 레이블과 색 대비 문제가 남았음. 이미 있는 지침을 적용하면 개선 가능.
3. **표현적 강도 조절:** '탁한 녹색 탈피'를 '높은 채도 면적 확대'로 오해. 원색의 적합성은 사용 범위·배경·제품 시각정보와 함께 판단해야 함.
4. **정보 구조 대 시각적 목적:** 정보를 빠르게 노출하는 것과 홍보 경험의 성공은 서로 다른 평가축.
5. **제품 비교 정확성:** 동일 물체의 색을 비교할 때 조명/각도/배경은 고정하고 조작 대상만 바꿔야 비교 의미가 있음.
6. **디테일 및 편집 품질:** 고립된 한 글자 줄바꿈, 불필요하게 큰 하단 유도 영역처럼 작은 구현 선택이 전체 인상을 손상할 수 있음.

## 차기 지침 검증 가설 (확정 규칙 아님)

- 가설 A: 홍보형/구매형 목표를 먼저 구별하면 브랜드 경험과 정보 접근성을 동시에 높일 수 있다.
- 가설 B: 제품의 고유 물성을 나타내는 서체·색·형태·모션을 선택하면 기능적인 UI 위주 스타일보다 높은 정서적 적합성을 얻을 수 있다.
- 가설 C: 고정 조건 제품 비교와 감상용 장면을 분리하면 브랜드 미감과 조작 정확성을 모두 보존할 수 있다.
- 가설 D: 반복되는 작은 시각적 문제는 가이드 비대화보다 기존 규칙 준수·국소 수정을 우선하는 것이 효율적이다.

## 판단 근거의 수준

- **확인한 것:** 5단계 HTML 및 버전별 테스트 기록, 사용자 피드백, 관련 이미지.
- **관찰/정성 판단:** 사용자 평가의 긍정·부정 변화 및 특정 디자인 디테일 선호.
- **아직 입증하지 못한 것:** 일반 사용자 전환율·체류시간·선호도 향상, 기기 전반의 접근성 완전 충족, v1.2 규칙의 여러 소재에 대한 통계적 우월성.
- **권고:** 제품/홍보형, 정보/콘텐츠형, 작업/도구형의 서로 다른 견본에서 같은 평가 기준을 반복 적용하고, 지침 누락인지 구현 미준수인지 구분할 것.

## 출처 범위

이 문서는 프로젝트 내부 사이트 구현, 사용자가 대화에서 직접 남긴 피드백, 버전별 `docs/` 테스트 기록, 아카이브의 `reference_guidelines/` 문서를 재구성한 자료이다. 외부 조사를 수행하거나 새 사용성 데이터를 만들어 추가하지 않았다.
