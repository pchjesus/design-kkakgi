# MUL. E7–E8 — 디자인 판단과 학습 기록

2026-10-17 · EXP-001 · 사용자 E8 승인 및 main 반영 요청 후 작성.

**목적:** 이번 결과가 나온 이유와 재사용할 방법을 남긴다. 개인 선호, 구현 사실, 일반화할 가설을 구분한다. 범용 지침 v1.2의 내용이나 DRAFT 상태를 자동 변경하지 않는다.

## 1. 이번 사례의 WHY / WHEN / HOW

| 축 | 이번 판단 | 실제 화면에서의 적용 |
|---|---|---|
| WHY — 목적 | 판매가 부가적인 제품 홍보. 물과 유리의 인상, 편안한 탐색 경험이 먼저다 | 가격·수량·장바구니를 HERO에 올리지 않고 별도 구매 패널에 유지 |
| WHEN — 제시 순서 | 먼저 감상 → 브랜드 이해 → 직접 탐색 → 세부 관찰 → 필요할 때 구매 | HERO 재조합, 브랜드 여백, COLORS 착지 후 조작·정보 등장, DETAILS, FAQ |
| HOW — 표현 방식 | 청량함과 부드러움은 유지하고 단단한 컵·유동적인 물을 구별 | 가벼운 제목과 읽기용 본문, 투명 표면/림/바닥, 무스케일 반동, 작은 색상 점 |

단순히 정보를 빨리 찾게 만드는 것만으로 홍보 사이트의 목적 달성을 설명할 수 없다. Catalog에서 배운 ‘구매 접근성 강화가 브랜드 감상을 압도할 수 있다’는 판단을 이번에도 적용했다.

## 2. 기존 지침·레퍼런스를 무엇에 사용했나

위 레퍼런스는 원리의 참고다. 이번 화면의 구체적인 비율·색·시간 값은 MUL. 맥락에서 선택한 구현값이며 범용 정답이 아니다.

## 3. 피드백으로 새로 정리된 교훈

### 3.1 여백이 많아도 답답할 수 있다

사용자는 E7의 우측 정보가 가운데로 몰린다고 평가했다. 원인은 페이지 전체 공백 부족보다, 우측 컨테이너의 폭·패딩과 짧은 항목의 교대 배치였다. E8에서는 최대 폭 1200→1440px, 제품/정보 비율 .83:1.17, 우측 패딩 제거, 전체 폭의 정보 행으로 대응했다.

**방법:** 문장을 더 줄이거나 화면 전체를 키우기 전에 ‘정보가 실제로 쓸 수 있는 폭’과 정렬축을 확인한다. 제목·제품·설명이 어떤 축에 몰려 있는지 본다. 이 판단을 모든 페이지의 넓은 배치 의무로 확대하지 않는다. 사용자가 좋아했던 브랜드 섹션의 좌측 여백은 유지했다.

### 3.2 분위기의 부드러움과 물체의 단단함은 함께 설계한다

사용자는 반동의 경쾌함과 높이를 긍정하면서 단단한 물성을 더 요청했다. 컵을 늘이거나 찌그러뜨리기보다 같은 19px 반동에서 낙하 가속, 접촉 직후 상승, 그림자 농도와 폭을 조정했다.

**방법:** 먼저 무엇이 변형 가능한지 구분한다. 유리는 강체, 물빛은 표면 변화, 페이지는 부드러운 전환이다. 모든 요소를 같은 탄성 곡선이나 squish로 처리하지 않는다. ‘말랑한 경험’이 곧 ‘말랑한 컵’을 뜻하지 않는다.

### 3.3 3D 거부 경험을 기술 자체의 영구 금지로 만들지 않는다

과거 거부된 것은 크고 별도의 패널/캐릭터처럼 보이는 3D 시도였다. 이번에는 사용자가 상하좌우 실제 모델링을 요청했다. E8은 페이지 내 제품의 크기·자리·주변 톤을 유지하면서 중공 mesh와 자유 회전을 추가했다.

**방법:** 피드백을 기술명 하나가 아닌 **크기·통합성·역할·품질**로 분해해 보존한다. 최신 명시 요청에 따라 기술을 바꾸되 과거의 실패 원인을 되풀이하지 않는다. 3D가 언제나 2.5D보다 우수하다는 결론은 아니다.

### 3.4 조작 가능성을 알리는 데 큰 패널은 필요하지 않다

사용자는 이전 조작부를 게임판 같다고 평가했다. E8은 알약형 버튼 테두리를 없애고 작은 재질색 점·텍스트·선택 링·초기화 문구로 바꿨다. 키보드 초점도 컵 전체의 큰 타원 대신 작은 안내 영역에 표시했다.

**방법:** 표시해야 하는 것은 컨테이너의 존재가 아니라 조작 위치·선택·복귀 방법이다. 경계를 줄일 때도 클릭 영역과 키보드 단서를 함께 보존한다. 테두리 제거 자체가 좋은 디자인이라는 의미는 아니다.

### 3.5 재조합은 요소의 관계를 드러낼 때 의미가 있다

HERO의 사진·제목·밑줄·본문·CTA는 한 덩어리가 아니라 역할별로 합류한다. COLORS는 컵의 정착 후 설명과 조작이 등장한다. ABOUT/DETAILS는 짧은 위치 복귀로 페이지의 연속성을 보완한다.

**방법:** ‘모두 페이드인’으로 시작하지 말고 물체→설명→행동의 관계를 정한다. 반복/재진입 조건·중단·입력 우선권도 함께 정한다. 글자별 분해나 긴 이동을 늘리는 것을 재조합의 발전으로 보지 않는다.

### 3.6 물성은 모델 파일이 아니라 실제 렌더링 결과에서 판단한다

처음 3D 재질은 지나치게 밝거나 불투명하게 보였다. 실제 브라우저를 보고 조명·노출·투명도·물 부피·림/바닥 표현을 수정했다. 초기 UMD의 경고는 로컬 ES module로 바꾸어 정리했다.

**방법:** 기능적으로 회전한다고 미적 완성까지 통과시키지 않는다. 반대로 보기 좋다는 평가만으로 상태·저장·접근성이 검증됐다고 말하지 않는다. 현재 재질은 스타일 표현이며, 정밀 광학·유체 물리의 검증 결과가 아니다.

## 4. 재사용할 작업 순서

1. **소재·목적·사용 장면을 한 문장으로 고정한다.** 이번에는 ‘물과 유리의 인상을 편안하게 경험하는 홍보 사이트’였다.
2. **이미 좋다고 평가한 부분을 보존 목록으로 둔다.** HERO 톤, 사진, 비대칭, 반동 높이, 구매 분리 등.
3. **불만을 원인별로 분해한다.** 취향/과제 해석/구현/상태/기술 한계를 섞지 않는다.
4. **레퍼런스는 역할 단위로 고른다.** 서체·공간·물성·전환의 참고를 지정하고 복제하지 않을 것도 기록한다.
5. **실험 범위를 묶되 기능 계약은 보호한다.** 이번은 별도 브랜치에서 레이아웃·모션·모델을 개선하고 기존 저장 키를 유지했다.
6. **실제 출력→입력→기존 기능을 확인한다.** 화면 폭, 모델 외관, 대각 회전, 초기화, 패널 색 동기화, 장바구니, FAQ를 연결해서 본다.
7. **사용자 채택과 검증 상태를 분리한다.** E8 채택은 사용자 승인 사실이다. 실물 모바일·Safari·강제 WebGL 실패까지 통과했다는 뜻이 아니다.
8. **결정 이유를 사례에 축적한다.** 같은 규칙을 계속 추가하기보다 다음 맥락에서 검증할 질문을 남긴다.

## 5. 근거 수준과 남은 질문

- **사용자 직접 확인:** E7 우측 폭의 답답함, 반동 높이·경쾌함의 긍정, 게임판 같은 조작부의 비선호, 3D 자유 회전 요청, E8 결과의 수용과 main 반영 승인.
- **구현·실행 확인:** 3D 출력·상하/대각 회전·초기화·색상 동기화, 1920/1440/390/320px 렌더링과 넘침, 장바구니 담기/삭제, FAQ, 미디어/의존 파일 무결성 검사. 세부 범위는 E7/E8 검토 문서 참조.
- **설계 가설:** 열린 정보 폭과 가벼운 조작부가 다른 홍보물에서도 편안함을 높일 가능성. 단단한 물체에 대한 timing/그림자 전략의 전이 가능성.
- **미검증:** 일반 사용자 선호·전환율, 실제 터치 기기·다른 브라우저, 저사양 FPS/발열, 정밀 재질/유체 물리, 모든 접근성 조합.
- **후속 질문:** 좁은 화면과 넓은 화면에서 같은 정보 위계가 유지되는가? 3D가 실제 제품 탐색에 도움이 되는가? 배경색 전환은 감상에는 좋지만 엄밀한 색 비교에는 불리하지 않은가? 3D를 선택적으로 끄는 모드가 필요한가?

E6의 톤 변화는 사용자 취향으로 유지한 감상 장면이다. 이를 고정 배경·조명을 사용하는 엄밀한 색상 비교와 동일하게 주장하지 않는다.
