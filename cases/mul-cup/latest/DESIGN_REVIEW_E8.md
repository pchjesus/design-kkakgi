# MUL. E8 — 열린 정보 배치와 자유 3D 회전

상태: **사용자 승인 · main 반영** (2026-10-17 20:40 KST 요청). 아래의 개발·검증 기록은 실험 당시 사실을 보존한다.
기준: E7 최종 `74c4327d99cae84bc25bf2f5ebd1240fb369b3fc`.

## 사용자 피드백과 판단

- 우측 정보가 가운데로 몰리고 화면 폭을 충분히 사용하지 않아 답답함.
- 기존 반동 높이와 경쾌함은 유지하되 단단한 컵의 접촉·반발감을 발전시킴.
- 상하좌우로 돌릴 수 있는 실제 3D 모델을 이번에 명시적으로 요청함. 과거의 큰 별도 3D 패널 거부는 물체 크기·페이지 통합에 관한 제약으로 유지하고, 이번 요청에 따라 모델링 방식은 확장함.
- 게임판 같은 조작 패널을 배경과 어우러지는 디자인으로 변경함.
- 첨부 화면은 판단에만 사용하며 저장소에 복제하지 않음.

## 구현

### 정보·조작부

- COLORS 콘텐츠 최대 폭 1200→1440px. 데스크톱 좌측 오브젝트/우측 정보의 비율을 .83:1.17로 조정.
- 우측 내부 패딩을 제거하고 3개 특징을 전체 폭의 행으로 구성. 항목은 왼쪽, 설명은 오른쪽에 배치. 제목·짧은 소개는 위에 유지.
- 모바일/태블릿은 읽기 순서와 단일 열을 보존함.
- 알약형 색상 테두리·카드 배경을 제거. 작은 재질색 점+텍스트, 선택 점의 얇은 링으로 상태 표시.
- 초기화는 가벼운 텍스트 조작으로 유지. 키보드 초점은 거대한 타원 외곽선 대신 안내 문구에 표시.

### 단단한 반동

| 단계 | 비율 | 관찰 목표 |
|---|---:|---|
| 낙하 | 0–54% | 112px 위에서 가속해 접촉 |
| 즉시 반발 | 54–76% | 접촉 후 바로 19px 상승. 기존 최대 높이 유지 |
| 정착 | 76–100% | 다시 내려와 종료 |

총 길이 880ms는 기존값을 유지한 구현 선택이다. 컵 scale 변형·찡그러짐·반복 흔들림 없음. 16°의 고정 구도를 유지하고 별도 접촉 그림자를 동기화한다. 기존의 착지 후 색상/설명 등장, 직접 입력 우선, 움직임 감소 처리를 유지한다.

### 실제 3D

- Three.js r160.1 ES module을 MIT 라이선스와 함께 저장소에 고정. 런타임 CDN·외부 모델·HDR 사진에 의존하지 않음.
- 회전 대칭 단면으로 외벽→둥근 입구→내벽→두꺼운 바닥까지 이어진 중공 mesh를 생성. 입구/바닥 링, 수면/물 부피, 곡면 마크를 추가.
- 가상 스튜디오의 면 광원/반사 환경을 코드로 생성. 이미지 2장의 바이트는 그대로 유지.
- 트랙볼 quaternion 드래그로 상하·좌우·대각 회전. 방향키는 두 축, Home/처음 각도로/더블클릭은 기본 구도 복원.
- 기존 색상 상태를 관찰해 구매 패널과 3D 재질을 동기화. 회전만으로 색·수량·장바구니는 변경되지 않음.
- 화면 진입 근처에서만 모델 코드 로드. DPR 최대 1.6, 입력/색상/크기 변화 시만 렌더. 자동 회전·상시 GPU 프레임 루프 없음.
- WebGL/모듈 실패 시 기존 SVG 좌우 회전으로 복귀하도록 구성. 실제 브라우저의 강제 context loss 시험은 아직 미실행.

## 표현 한계

모형은 실물 스캔이나 제조 치수 검증물이 아니다. 투명도·반사·물 색은 페이지 배경과 읽기 경험에 맞춘 스타일 표현이다. 특히 alpha blending을 혼합한 재질은 정밀한 광학 해석으로 간주하지 않는다. 물 부피는 컵과 함께 회전하며 유체 시뮬레이션은 아니다. 실제 환경맵/HDR 사진·외부 자산은 추가하지 않았다.

| 위험 | 대응·확인 |

| 오래된 좌우 회전 이벤트와 3D 드래그 충돌 | 3D 준비 이후 기존 changeAngle을 우회, capture 입력을 3D에 전달. fallback에서는 기존 경로 사용 |

구조 판정: **국소 분리**. 3D 모듈과 고정 라이브러리를 별도 파일로 분리했다. 전체 스타일/장바구니 구조 재작성은 하지 않았다. 재질 정밀화·저성능 모드·전체 CSS 정리는 이번 성공 여부를 사용자 검토한 후 별도 범위에서 판단한다.
