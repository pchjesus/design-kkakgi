# 사이 (SAI) — 논문과 문화 사이 | 버전별 소스 모음

이 압축파일은 기존에 제작한 블로그 프로토타입 **v0.1과 v0.2**를 버전별로 정리한 백업입니다. 원본 HTML/코드의 내용은 수정하지 않았으며, 비교용 스크린샷과 본 안내문을 추가했습니다.

## 폴더 구성

- `v0.1/index.html` — v0.1 전체 코드가 포함된 단일 HTML 파일. 브라우저에서 직접 열어보세요.
- `v0.1/README_original.md` — 원래 제공되었던 v0.1 사용 안내.
- `v0.1/previews/` — v0.1 데스크톱·모바일 첫 화면 참고 캡처.
- `v0.2/standalone.html` — v0.2 전체 코드가 포함된 단일 HTML 파일. 가장 쉽게 미리볼 수 있습니다.
- `v0.2/project/` — v0.2 HTML·CSS·JS 분리형 프로젝트 원본(`index.html`, `styles.css`, `seed-data.js`, `app.js`)과 원래 README, 설계 기록, 테스트 보고서.
- `v0.2/previews/` — v0.2 데스크톱·모바일 첫 화면 참고 캡처.
- `SHA256SUMS.txt` — 아카이브에 담긴 주요 소스 파일 무결성 비교용 SHA-256.

## 버전별 핵심 차이

| 버전 | 시각적 방향 | 주요 특징 | 실행 |
|---|---|---|---|
| v0.1 | 보라색 기반의 현대적·문화 중심 에디토리얼 | 샘플 6편, 검색·카테고리·북마크, 테마, 사용자 글 작성·삭제 | `v0.1/index.html` |
| v0.2 | 초록색 기반의 근거 중심 에디토리얼 | 학술 근거/해석/한계 구조 강조, 작성·수정·삭제, 폼 취소 경고, 키보드 포커스 관리 | `v0.2/standalone.html` 또는 `v0.2/project/index.html` |

## 실행 방법

1. ZIP을 압축 해제합니다.
2. v0.1은 `v0.1/index.html`, v0.2는 `v0.2/standalone.html`을 더블클릭해 브라우저로 엽니다.
3. v0.2 분리형을 사용할 경우 `v0.2/project/` 폴더 내 네 코드 파일을 **같은 폴더**에 유지해야 합니다. 환경에 따라 로컬 서버(`python -m http.server 8000`)에서 여는 편이 안정적입니다.

## 중요한 데이터·검증 주의사항

- 두 버전 모두 학술 논문과 대중문화 소재를 활용한 **교육용 블로그 프로토타입**이며, 별도의 서버·사용자 계정·공개 게시 기능은 없습니다.
- 개인 작성 글과 북마크 등은 브라우저 `localStorage`에 저장됩니다. **v0.1 키(`sai_custom_posts_v1`, `sai_bookmarks_v1`, `sai_theme_v1`)와 v0.2 키(`sai_v2_posts`, `sai_v2_bookmarks`, `sai_v2_theme`)가 서로 다릅니다.** 이 소스 묶음에는 버전 간 데이터 이전 기능을 추가하지 않았습니다. v0.1의 개인 글/북마크가 v0.2에서 자동으로 나타나지 않으며, 버전을 교체하기 전에 중요한 콘텐츠는 별도로 보관해야 합니다.
- 로컬 파일(`file://`)과 실제 호스팅 오리진은 브라우저 저장 동작이 달라질 수 있습니다. 서로 다른 폴더·브라우저·도메인에서 동일 저장 내용을 공유한다고 가정하지 마세요.
- v0.2의 `TEST_REPORT.md`는 제작 당시의 테스트 기록입니다. 이번 아카이브 제작은 **코드 원본·압축 구성·무결성**을 점검한 것으로 실제 브라우저 기능이나 학술적 정확성을 새로 검증한 것은 아닙니다.
- 캡처는 비교용 시각 자료이며 전체 길이, 모바일 동작 또는 모든 화면 상태를 대신 검증하지는 않습니다.
- 샘플 글과 참고문헌은 원본 프로토타입 그대로 보존했습니다. 정식 학술 활용 시 서지·DOI 및 원문 해석을 재검증해야 합니다.

## 버전 관리 메모

- v0.1의 원본 HTML과 `sai_research_culture_blog.html`은 같은 파일입니다.
- v0.2의 원본 `standalone.html`과 기존에 제공한 `sai_blog_v0.2_standalone.html`은 같은 파일입니다.
- 이번 ZIP은 버전 **정리본**이며, 버전이 다른 파일을 하나로 합치거나 기존 UI·기능을 변경하지 않았습니다.

## 이미지 보관 정책 변경 (2026-10-16)

v0.1·v0.2의 코드와 개발 문서는 유지하고, 저장소의 미리보기·스크린샷만 제거한다. localStorage 키 차이와 자동 데이터 이전 부재를 포함한 기존 동작은 이번 작업에서 변경하지 않는다.
