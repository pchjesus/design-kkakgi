# 사이 (SAI) — 논문과 문화 사이 | UI/UX v0.2

**질문 → 논문의 근거 → 연결·해석 → 한계**를 중심으로 읽고 쓰는 정적 블로그 프로토타입입니다.

## 실행 방법

### 1) 가장 간단한 방법
`index.html`을 Chrome, Safari, Edge 등의 브라우저에서 엽니다. `styles.css`, `seed-data.js`, `app.js`는 **같은 폴더**에 두어야 합니다. 또는 제공된 `sai_blog_v0.2_standalone.html`을 실행하면 파일 하나로 동작합니다.

### 2) GitHub Pages
저장소 루트에 `index.html`, `styles.css`, `seed-data.js`, `app.js`를 업로드합니다. Repository Settings → Pages → Deploy from a branch → `main` / root를 선택해 배포할 수 있습니다.

## 실제 구현 기능

- 6편의 **교육용 예시 글**: 애니메이션, 웹툰, 사회·인식, 일상·과학
- 제목·본문 키워드 검색 (`/` 단축키), 주제별 필터, 최신/오래된/제목순 정렬
- 글 상세화면의 질문, 연구 근거, 연결·해석, 한계, APA 7 참고문헌 및 DOI 외부 링크
- 북마크, 저장한 글 모음, 다크 모드 (브라우저 저장)
- 개인 글 작성, 수정, 삭제 (작성란 구조화; 브라우저 저장)
- 폼 미저장 변경사항 취소 경고, 키보드 포커스 트랩 및 종료 후 포커스 복귀
- 읽기 진행률, 반응형 레이아웃, reduced-motion 대응

## 중요한 한계

- 백엔드·회원관리·공개 게시·다른 기기 동기화·댓글·이미지 업로드는 **구현하지 않았습니다**.
- 개인 글과 북마크는 브라우저 `localStorage`를 사용하며, `file://` 저장 허용 여부는 브라우저 설정에 따라 다릅니다. 브라우저 데이터 삭제/사생활 보호 모드에서는 손실될 수 있습니다. 중요한 원고는 별도로 백업하세요.
- 개인 글의 링크를 외부인에게 보내도 해당 내용을 볼 수 없습니다. 실제 웹 호스팅에서도 개인 글은 자신의 브라우저 안에만 남습니다.
- 샘플 6편은 실제 출판된 연구 논문의 개념에서 출발한 **블로그 스타일 교육용 해설**입니다. 정식 체계적 문헌고찰이나 임상 지침이 아닙니다. 작품의 묘사는 구체적 작품의 공식 설정을 검증한 것이 아니라 해석 예시입니다.
- 표지 이미지는 모두 CSS 그래픽이며, 애니메이션·웹툰의 저작권 보호 이미지를 포함하지 않습니다.

## 폴더 구성

```
index.html            구조/페이지
styles.css            시각 토큰·반응형·접근성 스타일
seed-data.js          예시 게시물 6편 (서지·본문)
app.js                목록·라우팅·저장·글 작성 기능
README.md             실행·제약·구성
DESIGN_ADAPTATION.md  첨부 UI/UX 표준에서 블로그로 옮긴 정책
TEST_REPORT.md        자동화 테스트 결과 및 미검증 범위
```

## 보안·공개 전 유의사항

시연용 글 입력은 HTML 이스케이프 처리하며 DOI 링크는 `https://doi.org/10.` 도메인 형식으로 제한합니다. 실제 서비스로 배포하려면 계정 인증, 권한, 서버 데이터 저장, 스팸 방지, 백업, 이미지 저작권 관리, 개인정보 처리와 운영 정책을 별도로 설계해야 합니다.

## 콘텐츠와 디자인 기준

- `Educational_Simulator_UI_UX_Design_Standard_v1.0.md`의 **공통 원칙**(목적 우선, 점진적 공개, 시각적 위계, 정보의 정직성, 접근성, 검증)을 **블로그 맥락에 맞게 적용**했습니다.
- 시뮬레이터의 생리학 엔진·기기 조작·학습 진행 계약은 블로그에 적용하지 않았습니다.
- 디자인 원칙의 참고 틀: Apple HIG, WCAG 2.2 등 (첨부 표준 문서 참고).
