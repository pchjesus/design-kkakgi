# DECISION LOG

## D-001 — 초기 자료 보존과 운영 분리 (2026-10-16)

- **결정:** 지침, 레퍼런스 분석, MUL.·SAI 사례의 코드·문서·피드백·검증 기록을 하나의 독립 연구소 저장소에 보존한다.
- **범위:** 새 견본 제작이나 지침 정식 채택은 포함하지 않는다.
- **근거:** 연구 이력과 실험 자료를 장기적으로 비교·검증하기 위한 기반을 만든다.

## D-002 — Public 전환 및 이미지 비보관 정책 (2026-10-16)

- **결정:** `design-kkakgi`는 이미지 없는 정리 이력으로 Public 전환한다. 이미지 분석은 일반 ChatGPT 채팅에서 수행하고 GitHub에는 텍스트 분석 결과와 출처만 보관한다.
- **보존:** 모든 MUL.·SAI 버전의 코드, 문서, 피드백, 분석 결과와 지침 이력.
- **제외:** 외부 레퍼런스 이미지, 미리보기·스크린샷, 중복·임시 이미지, 이미지 포함 ZIP 및 이들 바이트가 도달 가능한 Git 이력.
- **제약:** 기존 플랫폼 캐시·외부 복사본의 완전 삭제는 보장하지 않으며, 정식 지침 채택은 여전히 사용자 승인 사항이다.


## D-003 — SIDE-001 별도 앱의 최종안 단일 운영 (2026-10-17)

- **사용자 승인:** 메뉴 추천 UI의 Warm-centered 최종 디자인과 하단 정렬·아코디언 모션을 현행 버전으로 적용한다.
- **운영:** `menu-roulette/main`을 유일한 실행 코드 기준으로 유지하고, 디자인 깎기 사이트에서는 정식 앱 링크와 사례 기록을 표시한다.
- **연구:** 청백색 실험의 비선호 이유와 비율·중앙 배치 등의 유효했던 부분을 텍스트로 남긴다.
- **비채택:** 과거 실험 디자인을 제품 기본값으로 병행 운영하지 않는다. 실험 브랜치/커밋 제거 여부는 별도 도구 권한에 따라 처리한다.
- **지침:** 범용 v1.2는 DRAFT 유지. 특정 실험에서 얻은 취향을 보편 강제 원칙으로 승격하지 않는다.
