## 0. 증거와 보관 원칙

- **[USER]** 사용자 발언에서 직접 확인되는 취향. 특정 이미지의 특정 요소에 대한 선호이지 모든 매체에서의 적합성 승인이 아니다.
- **[OBS]** 제공된 정적 캡처에서 육안으로 관찰 가능한 형태·색·배치.
- **[AI]** 사용자 발언과 관찰에서 도출한 해석 또는 적용 가설. 검증 전에는 일반화하지 않는다.
- **[NOT VERIFIED]** 원작자·제작기법·원본 URL·정확한 색상값/재질, 애니메이션·상호작용·접근성·반응형 및 사용성.
- 이미지는 이 채팅에서 분석했으며 **GitHub에는 원본, 썸네일, 스크린샷, base64 이미지, ZIP을 업로드하지 않는다.** 촬영·제작자·출처 URL은 대다수 미확인. 일부 캡처에는 스톡 워터마크가 표시되어 있으며 이를 재사용 허락으로 해석하지 않는다.
- 1차 REF-001~020의 기존 ID·확인 평가·파일을 유지한다. 아래의 26장은 새 자료이며 일부 작품을 연속 캡처한 것인지 확인하지 못했으므로 **26개의 독립된 취향 표본으로 통계 집계하지 않는다.**

사용자의 구체적 표현: “1번, 4번 이미지의 패턴과 입체감이 맘에 들어” (유화 묶음); “소스의 질감을 보여주면서 ... 공간의 어느 한 부분을 차지하며 구성요소로서의 존재감” (흰 소스 예시); “네번째 사진에서 하나의 곡선을 만드는데 ... 구성요소의 조화가 아름다워” (푸드 묶음).

| **분절된 요소들의 흐름**: 방울·재료가 배열되어 곡선을 만듦 | 기존 Atlas에 상대적으로 약했던 새 구성 축 | 사용자 직접 확인 | 곡선 자체 vs 이질적 재료들의 관계 중 무엇이 핵심인가 |
| **넓은 여백과 풍부한 질감의 공존** | '절제=밋밋한 표면'이라는 단순 등식을 반박할 가능성 | AI 해석 | 여백의 양보다 시각적 무게 배분이 중요한가 |

**확정된 것은 개인 취향의 일부이지 디자인의 보편적 성공이 아니다.** 이 문서의 '매트한 Rams 표면'은 사용자가 느낀 인상이며, 원제품의 실제 재료·마감 사양을 검증한 사실이 아니다.

## 4. 전용 가능한 표현 전략 — 강제가 아닌 후보

1. **넓은 질감형 스트로크**: 두께·폭·결이 있는 면을 단순 장식선 대신 화면을 구성하는 오브젝트로 사용. 후보: 제품/브랜드 비주얼, 아트워크, 표지. 실패 위험: 텍스트와 주요 객체를 가림.
2. **점열·분절형 경로**: 점·방울·조각이 각기 다른 크기·간격으로 한 흐름을 만드는 조형. 후보: 에디토리얼, 전시, 식품·라이프스타일 비주얼. 실패 위험: 내용과 무관한 곡선 장식의 반복.
3. **배경 대비형 발색**: 표면색보다 바탕의 명도·질감·광택을 함께 설계하여 색을 돋보이게 함. 후보: 물성 비교·제품 소개. 실패 위험: 색 재현 정확도가 필요한 발색표를 분위기 연출로 대체.
4. **정제된 매트 표면 + 고밀도 촉각 요소**: 조용한 배경 위 한 영역에 선명한 물성 집중. 후보: 제품 브랜딩·작품 소개. 실패 위험: 모든 화면을 '미니멀 배경 + 질감 덩어리'로 획일화.
5. **자연광의 온도·반사**: 파랑·초록·노랑과 따뜻한 붉은 계열이 만나는 색의 역할을 연구. 후보: 물·빛·자연 소재. 실패 위험: 실제 제품 특성과 무관한 무드 또는 브랜드 팔레트 충돌.

**매체별 판단:** 홍보·전시는 표현적 밀도를 적극 실험할 수 있으나, 장문 블로그는 읽기 폭·텍스트 대비를, 업무 앱은 조작/상태 정확성을, 의료·안전 UI는 오류 없는 정보전달을 우선한다. UI 안의 질감·입체감은 스크린샷만으로 기능성을 보증하지 않는다.

## 5. 후속 비교 실험 제안 (아직 실행하지 않음)

- **실험 A: 직접 발색 vs 간접 발색.** 동일 제품·정보·화면 크기를 유지하고 스와치 중심 구성과 배경·질감 대비 구성을 비교. 색상 정확성이 필요한 정보는 양쪽 모두 유지.
- **실험 B: 큰 단일 질감 면 vs 분절 곡선.** 동일한 메인 오브젝트·타이포그래피 조건에서 시각적 중심, 읽기 순서, 조형 균형 비교.
- **실험 C: 매트한 정제 표면 vs 도포된 입체 표면.** 목적이 다른 두 콘텐츠(감상형·정보형)를 활용하여 미감과 사용성을 별도로 평가.
- 각 실험의 비교 결과는 맥락 적합성, 미적 완성도, 접근성, 기능·상태 정확성으로 **분리**한다. 선호만으로 효과나 성과를 단정하지 않는다.

## 8. 2026-10-19 후속 시각 실험 — 질감의 강도와 조형적 절제

> 대상: 수분크림 / 진정 젤 / 영양 크림 / 립·색조의 **AI 생성 정적 예시 4종 × 2차**. 1차는 가상의 무라벨 제품과 제형 배경을 함께 만들었고, 2차는 제품을 제거하여 배경과 제형 조형만 남겼다. 두 차수는 통제된 비교 실험이 아닌 탐색적 반복 제작이며, 생성 이미지 원본은 저장소에 포함하지 않는다.

### 8.1 사용자 직접 피드백 [USER]

- **1차**: “질감이 좀 과하긴 한데”, 각각의 느낌은 잘 살렸다고 평가함. 즉 개념별 감각 전달에는 긍정적이었으나 질감의 강도에는 부정적.
- **2차 요청**: “좀 더 미니멀하고, 구도와 모양을 생각해서”, 제품 자체는 빼고 배경만 제작하도록 요구함.
- **2차 결과**: “지금도 너무 두꺼운 질감”이라고 재평가함. 이후 제작을 멈추고 분석·기록으로 전환.
- 사용자는 **유화의 입체적 물성 자체를 싫어한다고 말하지 않았음**. 제형형 생성 배경에서 두께가 과하다고 평가한 것이므로 모든 매체에 '얇은 질감'을 강제하지 않는다.

### 8.2 정적 결과에서 관찰한 점 [OBS]과 해석 [AI]

| 구분 | 확인 내용 | 결과 / 한계 |
|---|---|---|
| 제형별 감각 분화 | 1차의 흰 크림·투명 민트 젤·따뜻한 노란 크림·붉은 색조가 색·반사·투명도로 구분됨 | **[USER] 개념 전달 긍정**. 실제 제형 정확성은 NOT RUN |
| 과도한 두께 | 도포면 가장자리와 중앙의 두툼한 융기, 화면을 크게 점유하는 질감이 1·2차 모두 나타남 | **[USER] 질감 과다**. 사용자 의도 충족 측면 FAIL |
| 반복된 구도 | 큰 곡선형 스와이프가 네 가지 시안에 반복됨 | **[AI]** 재료는 달라졌지만 구성 전략의 다양성이 부족할 수 있음 |
| '미니멀' 해석 | 2차에서는 제품·텍스트를 제거했지만 큰 도포 흔적과 광택이 여전히 중심 | **[AI]** 오브젝트 수를 줄이는 것과 물성 강도·시각적 무게를 낮추는 것은 별개의 설계 변수 |
| 비교의 통제 | 제품의 유무가 바뀌고 생성 이미지의 조형도 동시에 달라짐 | **NOT RUN**: 동일 변수 통제에 의한 질감·구도 A/B 검증은 수행하지 않음 |
| 사용성/상태/접근성 | 배경 아트워크만 생성 | **NOT RUN**: 실제 UI·콘텐츠 적용 및 검증 없음 |

### 8.3 이번 연구에서 남길 디자인 판단 [AI — 조건부 가설]

1. **질감 ≠ 두께**: 촉각적 표현은 두꺼운 돌출만으로 결정되지 않는다. 매트함, 미세한 결, 표면 굴곡, 흐릿한 반사, 제형의 균일성 같은 여러 축을 각각 조절해본다.
2. **미니멀 ≠ 빈 공간의 양**: 오브젝트 수를 줄여도 남은 요소의 부피·면적·명암·광택이 과하면 화면은 여전히 무겁게 느껴질 수 있다.
3. **형태를 먼저 구성**: 먼저 조형 요소의 시작·끝, 곡선의 이유, 폭, 공간 점유율, 주변과의 시각적 균형을 정하고 물성을 결정한다. '예쁜 S자 크림 자국'을 기본값으로 삼지 않는다.
4. **단일 면 외에 분절된 배열도 시험**: 소스 점열과 플레이팅 사례처럼 서로 다른 모양·간격·색의 요소들이 하나의 흐름을 만드는 표현을 후보로 유지한다. 모든 과제에서 곡선 배열을 강제하지 않는다.
5. **배경의 역할은 부속품이 아님**: 검은 접시가 재료의 발색을 돋보이게 하듯 표면과 조명·색 대비를 함께 설계한다. 발색 정확도가 필요한 과제에서는 직접 스와치와 명시적 정보를 우선한다.
6. **감각적 매력과 목적 적합성을 분리**: 제품·브랜드 아트워크에는 물성 표현을 시도할 수 있지만, 장문 블로그·업무 도구·의료·안전 화면에서는 가독성·정보 위계·조작 가능성과 비교하여 적합성을 먼저 판단한다.

이 여섯 항목은 **개인 취향 기반의 설계 실험 후보**이지 \`Universal Visual Design & UI/UX Guidelines v1.2\`의 신규 필수 규칙이 아니다. 이후 디자인 작업에서 적합할 만한 경우 제안·시험할 수 있으나, 소재에 맞지 않으면 사용하지 않는다.

### 8.4 다음 실험에서의 검증 질문

- 이미지에 제품을 넣거나 빼는 변화 없이, **동일한 형태에서 질감의 높이·광택만** 낮추면 사용자의 평가는 달라지는가?
- 도포형 큰 면과 소스/점열처럼 분절된 형태를 같은 정보·컬러·캔버스에서 비교하면 어느 구성이 더 잘 맞는가?
- 매트한 평활 표면과 입체적 표면을 서로 다른 소재(제품 홍보 / 읽기형 콘텐츠 / 작업형 도구)에서 비교할 때, 미감과 실제 과제 성공은 어떻게 다른가?
- 브라우저 검증 시 명암 대비, 200% 확대, 작은 화면의 정보 위계, 이미지 위 텍스트 가독성, 성능·모션 감소를 **실제로 실행한 항목만** PASS로 기록한다.

### 8.5 기록의 경계

- **PASS**: 사용자 피드백 사실·시각적 차이·한계 분리 및 텍스트 기록.
- **FAIL (사용자 선호 충족)**: 2차 생성물에서도 질감이 지나치게 두꺼웠음.
- **NOT RUN**: 통제된 선호 A/B, 사람 대상 사용성, UI 구현, 실제 재료 물성·발색 검증, 접근성, 반응형, 인터랙션.
- **N/A**: 범용 지침 v1.2 개정, 특정 프로젝트 브랜드·기능·저장 변경.
