## 운영 규칙

1. 원본 스크린샷은 ZIP/채팅/임시 작업 영역에서만 활용하고 저장소에 커밋하지 않는다.
2. 개인 취향(주관)과 디자인 원칙(일반화 가능한 가설), 실제 검증 여부(실험)를 구분한다.
3. `UNRATED`를 AI가 A/B/C로 임의 변경하지 않는다. 의도적 수집이라는 사실만 확정된 것으로 취급한다.
4. 출처/원작자/라이선스는 대부분 **UNVERIFIED**. 자동 생성된 출처나 정확한 폰트명을 넣지 않는다.
5. 이미지 폐기 후 세부 시각 정보를 다시 볼 수 없다는 점을 감안하여 해시·관찰을 보존한다.
6. 가이드라인 개정은 별도 실험·승인 전까지 제안으로만 기록한다.
