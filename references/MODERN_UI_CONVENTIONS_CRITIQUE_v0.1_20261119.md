## 1. 원본 9종과 설계 목적·부작용

| # | [OBS] 항목 | 좋은 경우·설계 목적 [AI-HYP] | 미적/기능적 실패와 반례 |
|---|---|---|---|
| 01 | 넉넉한 여백 / White space | 그룹 사이 관계·읽기 집중·제품의 존재감을 위한 음영/호흡 | 작업 도구와 전문 대시보드에서 과도한 공백은 비교 불가·스크롤 증가·정보 은폐. [USER 기존] 왼쪽 아래에 큰 제목을 두는 레이아웃의 **의미 있는 오른쪽 여백**은 선호했다고 설명함 |
| 02 | 둥근 모서리 / Rounded corners | 부드러운 접촉·친근함·서비스의 안전한 톤 | 모든 위젯을 똑같이 둥글게 하면 구별성·정보 밀도 감소. 웨이파인딩처럼 **목적지향적인 각진 선**을 더 신뢰성 있게 느낀다는 사용자 관점과 구분 |
| 03 | 큰 제목 / Big type | 메시지 우선순위·브랜드의 첫인상 명확화 | 매 섹션 과도한 제목은 본문·수치·기능 밀어냄. [USER 기존] 첫 화면 대형 글꼴의 **대비·안정감·선명한 위계** 선호하나 모든 업무 카드에서 동일한 크기 요구 아님 |
| 04 | 포인트 색 하나 / One accent color | 제한된 행동 위계·중요 CTA의 식별성 | '포인트 1색'은 법칙 아님. 네이비/보라/라임/빨강 등 **상태·의미·소재에 따라 복수 색**이 필요할 수 있음. [USER 기존] 무난한 반복 팔레트보다 맥락에 맞는 과감한 대비도 요구 |
| 05 | 옅은 그림자 / Soft shadow | 높이·겹침·누를 수 있는 면·제품 물성 암시 | 모든 카드에 반복하면 광원 논리·위계 약화; 옅어서 영역이 사라지거나 ‘AI 기본 카드’처럼 보일 수 있음. 그림자보다 대비·테두리·간격이 유리한 환경도 |
| 06 | 얇은 구분선 / Hairline divider | 서로 가깝지만 분리해야 하는 정보의 경계 표시 | 희미한 선은 저대비·확대/해상도 환경에서 사라질 수 있음. 필요 없는 선을 늘리면 소음; 굵은 분리나 공백이 더 명확할 때도 있음 |
| 07 | 카드로 묶기 / Card layout | 독립된 요약/선택 단위를 명시하는 표면 영역 | 표·리스트가 맞는 밀도 높은 비교·워크플로를 카드로 분절하면 맥락 끊김. NN/g는 카드가 비교에 부적합할 수 있음을 경고 |
| 08 | 회색 단계 / Neutral grays | 텍스트·배경·테두리·보조 설명의 차이를 절제해 표현 | 회색 단계만 늘리면 핵심 정보·비활성/활성/도움말·선택 상태가 구분되지 않음; 약한 대비는 가독성 문제 |
| 09 | 다크 모드 / Dark mode | 어두운 환경·콘텐츠/발광 효과·사용자 환경 선호와 맞는 대체 테마 | 단순 반전만으로는 충분하지 않음. 대비·표면 계층·차트 색·장시간 사용·테마 보존·이미지/그림자 재검증 필요; 모든 브랜드에 적합한 것은 아님 |

## 2. 이미지 자체의 미적 분석 [OBS]

- **타이포그래피:** 검정색의 두꺼운 대형 한글 헤드라인, 파란 강조 단어, 번호·한글 제목·영문 보조명으로 위계를 만든 교재형 그래픽. 서체가 정확히 무엇인지는 이미지로 확정하지 않는다.
- **배경과 색:** 무채색에 가까운 부드러운 회백색 배경, 흰 회색 카드, 선명한 파랑을 소량 사용. 화면의 목적이 '시각적 스타일을 설명하는 것'이라 자기 설명적 예시로 기능한다.
- **레이아웃:** 세 칸×세 줄 반복 격자는 9개 항목을 한 화면에 찾아 비교하게 한다. 그러나 실제 사이트를 전부 동일 카드 격자로 만들라는 증거가 아니다.
- **물성과 이미지:** 약한 부조와 소프트 섀도, 얇은 외곽선. 실제 제품 소재·빛의 방향이나 인터랙션 상태를 충분히 보여주지는 못한다.
- **메시지:** 모던함을 즉시 재현하기 쉬운 9개 시각 장치를 포괄. 추상적 AI 프롬프트에서 **수단을 목적과 혼동할 위험**을 비판적으로 검토할 가치가 있음. 실제 게시 영상의 발화·의도는 미확인.

## 3. 기존 취향 지도와 교차: 일치·새 가설·충돌

| 구분 | 과거 사용자 직접 평가 [USER] | 이 자료를 통해 남길 해석 [AI-HYP] |
|---|---|---|
| **일치: 여백의 목적** | 'Eternia' 왼쪽 아래 큰 글자+오른쪽 여백의 안정감과 명료함을 높이 평가 | 여백 그 자체가 아니라 **시각적 무게중심/읽기 방향/타이포 배치**가 중요. 과도한 가운데 정렬·중립형 카드 그리드는 정답 아님 |
| **일치: 구조적 미니멀** | 심장 전도계 시뮬레이터의 '간편한 조작, 목적에 맞는 적절한 정보량과 위계'를 높이 평가 | 미니멀은 빈 화면이 아니라 **필요한 정보가 적절한 자리에 있는 상태**라는 해석과 연결 |
| **일치: 형태는 목적 기준** | 웨이파인딩은 각진 직선이 신뢰를 준다고 설명하고, 아이콘은 모서리·입체감의 부드러움에 관심 | 둥근 모서리 전역 강제는 사용자 고유의 목적지향적 형태 선택과 충돌 |
| **일치: 색의 개성** | 크림/그린/핑크, 샌드/브라운/일렉트릭 블루, 블루/라임 등 상황에 맞는 강한 대비도 탐구; 유사 AI 색감 반복의 개성 부족을 지적 | 단일 포인트 색 관례를 **목적에 맞는 시각적 위계와 소재 해석**으로 교체할 필요 |
| **일치: 물성 다양성** | 매트한 금속·유화의 두께와 결, 투명 젤·Liquid Glass·Plasma Glow 선호. Risograph는 색 비선호·조형 선호 | Soft shadow 하나로 물성을 대체할 수 없음. 미세 결/확산/굴절/광원/구조가 각기 다른 역할을 함 |
| **잠재 충돌** | 특정 디자인의 미니멀함을 좋아하지만 특색 없는 안전한 템플릿을 비판 | '미니멀 = 그리드·흰 카드·둥근 모서리·파랑 CTA'라는 공식 자체가 개인 취향과 어긋날 수 있음. 다만 이번 카드 9개 중 직접 비선호 판정을 내린 것은 아님 |

**확신 수준:** '기존 선호 발화'는 USER-CONFIRMED; 이번 예시들과의 관계는 AI-HYP 중간 확신. '둥근 모서리/회색 단계/다크모드가 싫다' 같은 결론은 **근거 없음**.

## 5. 외부 근거·반대 근거

- [RESEARCH] Nielsen Norman Group의 Aesthetic and Minimalist Design 설명은 **'미니멀 비주얼 스타일'과 UX 휴리스틱을 동일시하면 안 됨**을 명시한다. 중요한 내용에 집중시키는 것이 원리이고, 플랫·무장식 표현은 필수가 아니다.
- [RESEARCH] NN/g The Principle of Common Region은 경계선이 묶음 인지를 도울 수 있지만, 때로는 여백만으로도 더 단순하게 관계를 전달한다고 설명한다.
- [RESEARCH] NN/g Cards: UI-Component Definition은 카드가 독립 단위의 요약에는 맞지만 **여러 옵션을 빠르게 직접 비교할 때**는 예측 가능한 표 구조보다 불리할 수 있다고 설명한다.
- [OFFICIAL] W3C WCAG 2.2는 본문/비텍스트 대비, 초점, 색에만 의존하지 않는 상태 표시 등을 다룬다. 파란 포인트 하나/어두운 테마라고 자동으로 접근성이 성립하지 않는다.

## 6. 결론 — 원칙보다 작은 적용 질문

**'모던해 보이는가?' → '이 소재·사용자·과업에서 어떤 정보와 조작을 더 잘 보이게 하는가?'**로 질문을 전환한다.

이 9가지는 필요할 때 가져다 쓸 **표현 수단의 목록**이다. 어느 하나도 전체 프로젝트에서 금지하거나 의무로 강제할 근거가 없으며, **레퍼런스 관찰만으로 승인 지침 v1.3을 개정하지 않는다**. 새로운 웹앱·배포·디자인 실험은 진행하지 않는다.
