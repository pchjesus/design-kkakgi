## 운영 원칙
1. 사용자 확인 선호, AI의 해석, 적용 가설, 실제 사용성 테스트를 구분한다.
2. 현재 5개 항목의 A 평가는 '주요 시각적 선호'만을 의미한다. 나머지 15개는 평가 없음.
3. 사용자가 이번 자료에서 배제하고 싶은 이미지는 없다고 답했다. 이를 모든 프로젝트에 대한 적합성 승인으로 해석하지 않는다.
4. 출처·원저작자·라이선스·폰트명은 확인되지 않은 항목을 꾸며내지 않는다.
5. **원본 이미지와 ZIP을 GitHub 커밋에 포함하지 않는다.** 삭제해도 Git 과거 이력에 남을 수 있으므로 처음부터 커밋하지 않는다.
6. 범용 디자인 지침 v1.2나 시뮬레이터 전용 지침은 변경·승인하지 않았다.

## 이미지 원본 비보관

이 디렉터리는 텍스트 기반 분석·출처·검증 이력만 보관한다. 이미지 원본은 저장소에 올리지 않으며, 새 분석은 일반 ChatGPT 채팅에서 이미지를 확인한 뒤 Markdown 또는 JSON으로 기록한다. 출처가 불명확하면 `미확인`으로 표기하고, 분석은 실험 전까지 후보 근거로 취급한다.
