## 3. 이번 답변의 의미

- 이번 5장은 모두 직접 선호 이유가 확인되었으므로 `user_affinity_level=A`로 관리한다.
- 다른 **15장은 미평가(UNRATED)**. 앞서 수집한 사실만으로 일괄 A를 주지 않는다.
- 사용자는 “내 웹사이트에 적용하지 않고 싶은 이미지는 딱히 없었어”라고 답했다. 이는 **현재 의도적으로 제외할 사례가 없다는 자기보고**이며, 모든 디자인이 모든 웹사이트에 적합하다는 평가가 아니다.
- 과거의 '선명한 원색 선호' 가설은 **색의 명암·조명·재질이 함께 작동하는 표현을 선호**한다는 더 구체적인 가설로 수정해야 한다.
- 과거의 '초대형 제목 선호' 가설은 **서체의 두께·비례·물체와의 위치 관계·보조 정보의 양**에 대한 선호로 구체화한다.
- 별도의 UX/A11y/모션 실측은 전혀 수행하지 않았다.

## 4. GitHub 보존 및 변경 정책

사진과 현재 ZIP 자체는 저장소에 커밋하지 않는다. 원본 이미지 SHA-256과 ID는 JSON에 기존 값 그대로 남겨, 별도 보관한 자료와 대응할 수 있게 한다. 이 문서는 개인 디자인 선호 연구 결과이며 범용 지침 및 시뮬레이터 지침의 수정 승인으로 간주하지 않는다.
