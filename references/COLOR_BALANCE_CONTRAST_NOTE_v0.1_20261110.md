# COLOR-001 — 60·30·10 색면 구성과 대비의 개성

> 등록일: 2026-11-10 · REFERENCE / 사용자 선호 기록 · 범용 기준: Universal Visual Design & UI/UX Guidelines **v1.3 APPROVED** (미변경)
>
> **자료:** 사용자가 제공한 Instagram Reels **정적 캡처 1장**. 화면 상단 60% main / 30% second / 10% loud, 그리고 Mellow / Summer Noise ’26 / Echo 시안 3종. 원본 영상 링크·제작자·라이선스·정확한 HEX·실제 색면 픽셀 비율은 미확인. **이미지·영상·폰트·타사 에셋은 GitHub에 올리지 않는다.**
>
> **번호:** COLOR-001은 기존 REF-001~072의 연속 번호가 아니라 별도의 색채 취향 사례.

## 1. 사용자 직접 반응 [USER]

| 레퍼런스 | 사용자 평가 | 확정 범위 |
|---|---|---|
| **A — Mellow:** 버터크림색·짙은 그린·핫핑크 | “버터크림색이 들어간 첫번째 이미지가 눈에 들어왔어.” / “결론적으로, 첫번째가 괜찮은데?” | **셋 중 가장 선호** |
| **B — Summer Noise:** 강한 블루·밝은 중립색·라임 | 파란색과 라임의 강한 대비에서 “확 청량함”, “매력” | **긍정적인 대안** |
| **C — Echo:** 딥 네이비·코발트 블루·오렌지 | “전체적으로 무난한 느낌”, “인베스팅닷컴 보는 기분” | 친숙·평범하다는 인상. 특정 브랜드와의 객관적 유사성이나 강한 비선호 확정 아님 |

- **변주 [USER 제안 / 아직 미평가]:** A의 핫핑크를 **주황색**으로 바꿔도 괜찮을 것 같다는 아이디어. 실제 시안을 본 선호 결과는 아니다.
- **중요한 문제의식 [USER]:** 최근 제작한 사이트들이 A처럼 안전하고 비슷한 색채로 수렴해서 **특색이 부족하거나 AI가 만든 티가 날 때가 있다**고 지적. 제품/상황에 맞으면 B·C처럼 **고채도 대비를 과감히 시도**하자는 뜻이지, 모든 화면에 강한 색을 쓰라는 지시는 아님.

## 2. 이미지에서 확인한 시각적 역할 [OBS]과 해석 [AI-HYP]

| 사례 | 정적 화면의 색채 구조 [OBS] | 가능성 [AI-HYP] | 역효과·한계 |
|---|---|---|---|
| A | 따뜻한 연크림 면 + 깊은 그린 구조 + 작은 핑크 악센트. 세리프 타이포와 강한 강조의 대비 | 안정감 속 의외성. 핑크→오렌지는 더 따뜻할 수 있으나 예기치 않은 긴장감이 약해질 수 있음 | 강조색 면적 확대 시 차분함 소실. 본문·버튼 대비 실측 필요 |
| B | 일렉트릭 블루의 큰 색면 + 밝은 문자/정보 + 라임 강조, 큰 굵은 제목 | 쾌활·청량·주목성; 스포츠·행사·홍보 같은 상황에서 탐구 가치 | 의료·업무형 고밀도 화면에 무비판적 이식 시 피로·정보 경쟁 |
| C | 깊은 네이비/블랙 바탕 + 블루 정보 위계 + 오렌지 초점 | 기술/금융 제품에서 친숙함·예측 가능성 | 제품만의 정체성이 없으면 흔한 템플릿 인상 |

**60:30:10**은 캡처가 제시하는 **역할·비중을 생각하기 위한 휴리스틱**이다. 실제 화면에서 정확한 60%, 30%, 10% 면적을 검증한 게 아니며 범용 강제 규격도 아니다. 작은 고채도 면적이 더 큰 시각적 무게를 가질 수 있다.

정확한 색상 코드/디자인 토큰은 계측하지 않았다. 대화에서 임의 예시로 제시된 HEX를 이미지의 실제 색으로 확정하지 않는다.

## 3. 기존 취향 지도와 비교

- **일치 [USER + 이전 관찰]:** 특정 파란색이나 특정 파스텔의 고정 선호보다 색채의 **명암·온도·발색·공간에서의 역할**을 중요하게 판단해 왔다. 유화의 색면·제형의 물성·음식 플레이팅에서의 강조·여백 관심과 연결할 수 있다.
- **새로 확인 [USER]:** 버터크림/그린/핑크의 선호 순위, 블루/라임의 청량한 대비에 대한 긍정, 익숙한 테크 팔레트에 대한 무난함 평가. **핑크→오렌지는 후속 실험 가설**.
- **보완 [AI-HYP]:** 따뜻하고 조화로운 팔레트만 반복하면 개성 부족 문제가 생길 수 있다. **색채의 조화 + 목적 있는 긴장감**을 함께 설계할 가능성을 검토.
- **주의:** A를 향후 모든 사이트의 기본 색으로 만들면, 사용자가 지적한 ‘획일성’ 문제를 재생산한다.

## 4. 향후 선택 질문 — 새 강제 규칙이 아닌 평가 가설

1. 목적·매체·브랜드가 실제로 요구하는 분위기를 정의했는가? 지난 프로젝트의 베이지·그린을 그대로 복제하지 않았는가?
2. 주조색은 배경의 톤, 보조색은 정보 구조, 강조색은 중요한 시선을 담당하는가? 실제로는 다른 역할 분담이 더 나을 수도 있다.
3. 고채도 B/C 팔레트가 제품의 개성을 살리는가, 아니면 사용성을 해치는가?
4. 색뿐 아니라 타이포·구도·이미지·물성도 해당 제품의 특성에서 출발하는가?
5. 명암·텍스트 대비·상태 구별·모바일·색각 다양성은 실제 렌더에서 확인됐는가?

**운영:** 이번 색채 레퍼런스는 등록 후 종료. 사용자가 유사한 사례를 다시 가져왔을 때 공통점·차이·반례를 비교해 보강한다. 별도 시안 제작/범용 지침 개정은 자동으로 하지 않는다.
