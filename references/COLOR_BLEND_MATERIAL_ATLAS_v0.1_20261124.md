# COLOR-004 — 투명 재료와 블루 혼합비가 만드는 색의 연속성

> 2026-11-24 등록 · 2026-11-21 제공 정적 Instagram 릴스 캡처 1장 분석. **B 선택형 색채·물성 심층 분석**(시각적 관계 중 핵심 3개만). [COLOR-001~003](COLOR_APPLICATION_MATERIAL_ATLAS_v0.1_20261112.md)의 후속 **별도 계열**, SRC 원자료 건수에 합산하지 않음. 범용 v1.3 APPROVED·제품/Pages 변경 없음.

## 1. 자료·증거·선호

- **[OBS]** 화면 계정 표시 `@artcraftblend`, 상단 `Crystal CLEAR + Hyper BLUE`, 다섯 덩어리의 반투명한 푸른 젤처럼 보이는 물체와 양쪽 혼합 비율. 각 물체 중앙에 영어 색명.
- **[NOT RUN]** 릴스 실제 재생, 배합 성분·비율 측정, 재료 특성, 카메라/광원·화이트밸런스 확인, 색채 계측, 게시물 원본 URL·저작권 확인. 캡처 화면색은 재료 고유색이 아니다.
- **[USER]** 직전 자료에 대해 '그냥 다 괜찮음'이라고 포괄적으로 응답. 특정 5개 중 한 색을 최선호했다고 기록하지 않는다. 직접 평가 근거는 전반적 긍정/수용 가능성까지.

## 2. 원본 표기와 정적 색 변화

| Clear:Blue 표시 | 중앙 이름 | [OBS] 이미지에서 보이는 색 | [AI-HYP] 인상 |
|---|---|---|---|
| 90:10 | MINT LAGOON | 연한 민트·녹청, 밝은 반사광 | 온화하고 맑음 |
| 70:30 | TROPICAL TEAL | 더 선명한 녹청/터쿼이즈 | 청량하고 활발함 |
| 50:50 | MERMAID BLUE | 청록에서 선명한 시안·블루 | 맑음과 강한 발색의 중간 |
| 30:70 | OCEAN BLUE | 상대적으로 더 짙은 파랑 | 깊고 차가운 인상 |
| 10:90 | FRENCH BLUE | 푸른 바탕에 보라 기운도 보임 | 강렬하고 깊이감 있음 |

**관찰 경계:** 위의 비율은 화면에 *표기된* 값이며 실측한 혼합량이 아니다. '투명+파랑'이라는 두 재료의 실제 색혼합 법칙·선형 채도 변화·파장값을 증명하지 않는다. 숫자 HEX/정량 밝기·채도는 계측 전까지 원색값으로 기록하지 않는다.

## 3. B 분석 — 세 개의 결정적 관계

1. **배열과 비교의 관계 [OBS → AI-HYP]**: 비슷한 크기의 둥글고 불규칙한 물체 다섯 개가 세로 정렬되고 양옆에 90:10부터 10:90까지 숫자열이 붙는다. 형상이 크게 바뀌지 않아 혼합비에 따른 색 이동이 비교의 주제가 되기 쉽다. 다만 마지막 숫자는 화면 오버레이와 겹쳐 일부 가독성이 떨어진다.
2. **투명도·빛·내부 구조의 관계 [OBS → AI-HYP]**: 표면의 큰 하이라이트와 내부의 기포처럼 보이는 점, 가장자리에서 달라지는 색 농도가 평면 단색과 다른 물성을 암시한다. 실제 점도·재질·촬영 기법은 사진만으로 확정 불가. 색채의 매력은 단지 RGB 값이 아니라 광원·배경·두께·표면 반사와 얽혀 있을 가능성이 있다.
3. **색 계열과 배경의 관계 [OBS → AI-HYP]**: 크림빛 중립 배경 위 푸른 계열이 연속 배치돼 색 차이가 드러난다. 상단의 흰/검/파랑 서체 조합이 두 재료 이름을 분리하고 중앙의 흰 제목은 각 젤 위에 놓인다. 단, 흰 글자는 밝은 민트 젤과 겹치는 구간에서 읽기 어려울 수 있다.

## 4. 응용·반례·기존 지식과의 관계

- **가능성 [AI-HYP]:** 투명한 제품·색조 화장품·수중 주제·브랜드 그래픽에서 같은 물성 안의 색상 스펙트럼을 보여줄 수 있다. 색 단계의 의미를 텍스트와 함께 제공하는 실물 재료 교육에도 참고 가능.
- **실패/반례:** 인접한 블루·시안의 색차만으로 '오류/정상/성공' 같은 상태 구별을 하거나, 반사광과 반투명 글자를 장문·고밀도 업무 UI에 그대로 적용하면 명료성이 악화될 수 있다.
- **연결:** [REF-003 젤리 같은 푸른 링에 대한 사용자 직접 선호](USER_CONFIRMATIONS_v0.3_20261016.md), [취향 지도 H-03/H-04](PREFERENCE_ATLAS_v0.3_20261016.md), [COLOR-001](COLOR_BALANCE_CONTRAST_NOTE_v0.1_20261110.md) 대비의 역할, [COLOR-002·003](COLOR_APPLICATION_MATERIAL_ATLAS_v0.1_20261112.md) 실제 제품과 UI 색 연결.
- **차별점:** COLOR-001이 화면의 여러 색 역할·비중을 다루었다면, COLOR-004는 **단일 색 계열이 혼합비 표시와 광학적으로 보이는 재질에 의해 어떻게 변하는지**를 다룬다. 이를 '사용자는 모든 블루 계열을 특히 선호한다'는 규칙으로 승격하지 않는다.
