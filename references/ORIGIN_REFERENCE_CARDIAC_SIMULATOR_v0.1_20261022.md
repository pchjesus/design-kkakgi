## 1. 왜 특별하게 보존하는가 — 사용자의 직접 평가 [USER]

사용자는 이 디자인을 **디자인 탐구를 시작하게 만든, 기념비적인 사례**로 보고 있으며, 시간이 지난 현재에도 비슷한 수준으로 만족하는 디자인을 쉽게 찾지 못했다고 설명했다.

직접 좋게 평가한 속성은 다음과 같다.

- **색감**: 과도한 장식 없이 필요한 내용에 사용된 푸른 강조색과 중립적인 바탕.
- **배치**: 제목/설명/시각적 대상/결과 설명/조작부의 위치.
- **목적에 맞는 정보량**: 학습을 돕는 수준에서 절제된 내용.
- **정보 위계**: 중요한 학습 대상과 현재 단계를 분명히 구분.
- **간편한 조작 및 심플한 UI**: 부차적 메뉴로 분산되지 않는 집중형 구성.

이것은 **개인적·미학적 호평과 화면의 목적 적합성에 대한 사용자 판단**이다. 실제 학습 효과·조작 성공률·임상 정확성·보조기기 접근성이 검증되었다는 의미는 아니다.

## 2. 정적 화면의 관찰 [OBS]

| 부위/요소 | 이미지에서 확인되는 특징 | 그로부터 가능한 한정적 해석 [AI] |
|---|---|---|
| 상단 학습 도입 | '**3. 심장의 전도계**'라는 번호가 있는 굵은 제목; '심장은 아무 곳에서나 전기가 발생하지 않는다. 정해진 길이 있다.'라는 두 문장의 설명 | 학습 단계와 핵심 내용을 먼저 알리는 정보 위계 |
| 콘텐츠 외곽 | 흰 바탕 위에 얇은 회색 경계·둥근 모서리의 큰 시뮬레이터 영역 | 인터랙티브 학습 영역과 일반 설명의 구분 |
| 심전도 도식 | 회색 P–QRS–T 파형 중 QRS 부분이 선명한 파랑으로 강조되고 작은 라벨·표시점이 있음 | 전체 맥락을 남겨두면서 현재 집중 구간만 강조 |
| 심장 도식 | 회색 심장 외곽과 내부 파랑 경로·점·음영, 동방결절/방실결절 범례 | 심전도 구간과 기관 내 전도 경로를 나란히 이해하도록 배치 |
| 단계 설명 | 경계 아래에 'QRS 복합체: 신호가 심실 전체로 퍼집니다.'라는 문구 | 현재 선택 단계와 연결된 해설로 보임. **사용자 제공 문구 그대로 기록하며 임상 정확성을 여기서 승인하지 않음** |
| 하단 조작 | '심전도 구간' 레이블, 점표시가 있는 수평 슬라이더, 원형 손잡이 및 아래쪽 아이콘 | 단계 이동을 의도한 주 조작으로 보이나 실제 실행·키보드/터치 작동은 미검증 |
| 기타 상단 버튼 | 닫기, 되돌리기처럼 보이는 아이콘과 반응 버튼처럼 보이는 기호 | 목적을 단정할 수 없음; 아이콘을 눌렀을 때의 결과는 NOT RUN |

**주의:** 화면 내 그래픽·설명은 교육 콘텐츠이며, 스크린샷만으로 애니메이션의 동기화·해부학적 정확성·실제 상태 엔진의 존재를 확인할 수 없다.

## 3. 이 디자인이 강하게 작동하는 이유 — 판단 가설 [AI]

### 3.1 위에서 아래로 이어지는 단일 학습 흐름

**제목/짧은 도입 → 심전도와 심장 시각화 → 현재 단계 해설 → 구간 선택**으로 이어진다. 항목이 많은 화면을 카드 단위로 쪼개는 대신 하나의 대상에 집중한 구조로 보인다.

### 3.2 강조색의 기능적 역할

회색은 배경적 구조, 파랑은 현재 주목할 흐름·선택된 파형, 검정은 설명 텍스트로 인지된다. **색의 역할이 일관돼 보이는 점**이 미적 정돈감과 정보 이해를 함께 뒷받침할 수 있다. 다만 색만으로 정보가 전달되는 영역이 있는지는 별도 검토가 필요하다.

### 3.3 큰 여백과 작은 핵심 오브젝트

시각화 주변의 여백은 텅 빈 장식이 아니라 **내용을 분리하고 현재 대상에 주목시키는 공간**으로 읽힌다. 이는 브랜드 포스터에서 여백이 글자를 부각하는 용도와는 다르며, **학습 집중을 위한 정보 밀도 조절**이라는 목적이 있다.

### 3.4 인터랙션의 후퇴와 주제의 전면성

하단 슬라이더가 인터페이스를 지배하지 않는다. 조작부는 낮은 위치에서 학습 내용을 뒷받침하고, 도식이 시각적 중심을 유지한다. 이는 기계적 모션·화려한 패널이 없어도 **대상을 중심에 두는 UI**가 매력적일 수 있다는 사용자 선호와 연결된다.

### 3.5 서체의 조용한 위계

독특한 디스플레이 서체나 과도한 장식 없이도 제목, 짧은 설명, 파형 라벨, 조작 라벨이 크기·위치에 따라 구별된다. **타이포그래피의 성공을 독특한 글꼴의 사용 여부로 환원하지 않는다.**

## 4. 기존 취향·디자인 철학과의 관계

| 이전에 관찰한 관심 | 이 기원 화면에서 읽을 수 있는 대응 | 해석의 경계 |
|---|---|---|
| 목적이 형태를 결정함 | 의료 교육용이므로 물성 과장·광고형 타이포보다 이해 가능한 도식이 앞섬 | 이 구조가 모든 교육 과제의 최선은 아님 |
| 형태/색이 기능을 분명하게 보여야 함 | 파랑 강조와 작은 단계 해설이 하나의 학습 장면을 구성 | 실제 조작·학습 성과 NOT RUN |
| 균형 있는 비대칭과 여백 | 화면 내 큰 시각적 여백이 집중과 안정감에 기여하는 것처럼 보임 | 여백의 양이나 정렬이 최적이라는 실험 결과 없음 |
| 디터 람스식 절제·기능적 아름다움에 관심 | 최소화된 조작, 분명한 정보, 시각적 정돈 | 특정 산업디자인 제품의 외형 복제 또는 디자인 계보의 증명 아님 |
| 타이포그래피의 목적 적합성 | 제목의 명료함을 위해 표현적 서체의 개성을 절제 | 홍보용 거대 헤드라인과는 목적이 다름 |
| 물성·촉각적 그래픽에 관심 | 이 경우 물성 효과가 거의 없는데도 큰 호감을 보임 | 모든 디자인에서 3D 질감이 필요하다는 가설을 **반박하는 균형 사례** |

**중요:** 이 사례는 '미니멀하면 언제나 좋다'의 증거가 아니라 **사용자 과업에 충분한 정보량과 적절한 강조를 선택한 화면을 사용자가 오랫동안 긍정적으로 평가한다**는 기록이다.

## 5. 강점과 퇴보 가능성을 분리해서 보존

### 바꾸지 말아야 할 강점(사용자 선호를 기준으로)

1. 설명/심전도/심장 도식/현재 단계/조작의 **논리적 인접성**.
2. 흰색·회색을 중심으로 한 **시각적 정숙함**과 파란색의 제한적 강조.
3. 필요 이상의 패널·탭·상태 배지를 만들지 않는 **집중형 정보 밀도**.
4. 학습 대상을 압도하지 않는 조작부와 보조 설명.
5. 둥근 경계·얇은 선·단정한 문자 크기 위계가 만드는 친근하지만 과장되지 않은 인상.

### 현재 사진만으로 판단할 수 없는 사항 또는 잠재적 위험

- **임상/교육 정확성:** QRS 복합체의 전기생리학적 의미, 동방·방실결절에서의 실제 활성화 시간 관계, 심장 도식의 위치 및 표현을 전문적으로 검증하지 않았다. 설명의 단순화와 정확성은 별도 점검 필요.
- **상태 및 실제 조작:** 파형-도식-설명-슬라이더가 동일 단계로 연결되는지, 변경·되돌리기·취소가 제대로 동작하는지 확인되지 않았다.
- **가독성·접근성:** 도식에 붙은 극소형 레이블, 희미한 회색 선, 아이콘 의미, 슬라이더 키보드·터치 동작, 200% 확대/좁은 화면, 색각 다양성은 실제 시험이 필요하다.
- **매체 확장:** 데스크톱 스크린샷의 여백과 비율을 모바일로 단순 축소하면 중요 요소가 너무 작아질 수 있다.
- **브랜드화 오용:** 파랑/흰색·심장 도식·둥근 카드라는 외형을 다른 서비스의 기본 템플릿으로 재사용하면 목적 우선 원칙과 충돌한다.

## 6. 향후 실제 비교 실험 후보

> 이 파일은 **실험 아이디어를 보존할 뿐 시안 구현을 요구하거나 승인하지 않는다.**

- **비교 A — 정보 밀도:** 현 화면의 집중형 구성 vs 동일 핵심 내용을 유지한 보조 정보 노출형. 이해·도달 시간·시각적 평온함을 분리 관찰.
- **비교 B — 강조 방식:** 파랑 강조 단독 vs 파랑 + 문장/패턴/마커로 상태를 중복 표현. 색각·가독성·의미 전달 확인.
- **비교 C — 조작부의 위치:** 하단 고정형 vs 도식 근접형. 정보·기능 동일 조건에서 손동선·시선 이동·사용자 선호 비교.
- **비교 D — 모바일 적응:** 도식의 순서·크기·단계 설명을 재배치하되 구조·정보·기능은 유지.
- **보존 조건:** 원본 사진의 강점을 기저선으로 두고 변경 요인을 1개씩 확인. 이미 승인된 기존 웹앱 코드를 덮어쓰지 않는다.
