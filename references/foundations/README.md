## 근거 계층과 사용범위

| 표시 | 뜻 | 검증 범위 |
|---|---|---|
| [LECTURE] | 제공된 교수 강의 PDF의 진술 | 강의가 그렇게 설명함을 확인. 외부 통계 검증과 별개 |
| [STANDARD-ABSTRACT] | ISO 공식 유료 표준 소개 페이지 | 범위·버전·요약 확인. 유료 표준 전문은 미열람 |
| [OFFICIAL] | FDA, W3C, IETF 등 공개 기관 문서 | 명시된 근거/권고/규격 확인, 개별 제품의 준수 여부와 별개 |
| [AI-HYP] | 설계 제안·반례·적용 가설 | 실사용 효과 미입증 |
| [NOT RUN] | 미수행 시험 | 실제 동작·임상·사용자 평가 미확인 |

## 기존 지침과의 관계

[범용 v1.3](../../guidelines/universal/Universal_Visual_Design_UI_UX_Guidelines_v1.3.md)의 목적/흐름/구조/표현·상태·접근성·위험별 검증을 뒷받침하는 **비규범적 연구층**. 기존 기능이나 데이터 보존, 전문 안전 계약을 덮지 않는다.

**새 레퍼런스 처리:** 먼저 해당 REF/SRC/STYLE 등의 문서에 분석·등록하고, 필요한 부분만 이론과 연결한다. 연구 실험이 레퍼런스 수집을 밀어내지 않도록 한다.

**권리:** 원본 강의 PDF·그림·소셜 미디어 캡처는 공개 GitHub에 업로드하지 않으며 사용자 제공 자료의 요점과 분석만 기록한다.
