# 과업 중심 사용성 평가 카드 v0.1

> 2026-11-16 · 연구용 **시험 계획 템플릿**. 사용자 시험·임상 전문 검증이 수행된 것은 아니다. [FOUND-001](FOUND-001_UCD_NURSING_USABILITY.md).

## 1. 사용자·환경·과업

| 항목 | 기록 |
|---|---|
| 앱/사이트 버전과 환경 | 실제 실행 주소, 화면, 브라우저, 입력장치 |
| 대표 사용자와 조건 | 숙련도, 역할, 언어, 보조기기, 압박/소음/이동 |
| 구체적 과업 1개 | 시작 상태, 목표, 완료의 실제 증거 |
| 보존할 기능·상태·데이터 | 저장·복구·뒤로가기·접근성 계약 |
| 성공/부분 성공/실패 기준 | 단순 완료 버튼 표시가 아니라 실제 반영 결과 |
| 위험/회복 | 잘못된 환자, 단위, 중단, 경고 등 해당 분야별 추가 |

## 2. 실제 관찰

| 축 | 측정 질문 |
|---|---|
| 효과성 | 끝까지 정확하게 완료했나? 재시도/오류/부분 성공은? |
| 효율성 | 소요시간, 클릭·경로, 도움 요청, 되돌림과 작업 부담은? |
| 주관적 만족 | 직후 인터뷰 및 필요시 SUS 10문항. **SUS는 성공률 퍼센트가 아님** |
| 정보탐색/흐름 | 찾고자 하는 정보를 어느 지점에서 발견/이탈했나? |
| 상호작용/상태 | 진행·저장·완료·실패·취소·복구가 실제 상태와 일치했나? |
| 접근성 | 키보드, 포커스, 크기, 의미 있는 상태 알림, 대비 |
| 안전/전문 검증 | 의료 등에서는 위험 오류와 환자 안전성·임상적 정확성 **별도로** |

## 3. 결과 보고

- 관찰 사실과 **AI 해석을 구분**.
- 미적 완성도·맥락 적합성·사용성·접근성·기능 및 안전성 각각 판정.
- 원인: 지침 누락/구현 미준수/콘텐츠/표본 취향/렌더링 또는 환경.
- 필요한 수정과 보존할 장점, 회귀 위험.
- **PASS / FAIL / NOT RUN / N/A**. 실제 시험이 없으면 NOT RUN.

예시(실행 안 함): 가상 환자 교육 기록에서 사용자 식별 → 교육 항목 선택 → 실제 저장 완료 → 화면 재진입을 관찰하는 과업. 실환자 정보는 사용하지 않으며 임상 평가를 대체하지 않는다.
