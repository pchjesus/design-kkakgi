> 2026-11-16 최초 작성 · 2026-11-20 장면 분석 선택 기준 추가. 사용자의 지속 운영 요청: **레퍼런스를 가져오면 먼저 분석하고 등록**. 심화 논문 조사·실험은 필요할 때만 후속 수행한다. 본 프로토콜은 승인된 범용 v1.3, 제품 코드, 배포를 변경하지 않는다.

## 등록 6단계

1. **자료 직접 확인:** 화면·PDF·URL에서 실제 확인되는 것을 관찰. 읽을 수 없는 글씨·움직임·효과는 확인했다고 쓰지 않는다.
2. **분류와 중복 조회:** 기존 Visual(REF/COLOR/STYLE/ORIGIN), Patterns(SRC), Foundations(FOUND), Systems, 실험(LAB) 계열 중 분류. 비슷한 주제는 교차링크. 기존 ID 재번호 금지.
3. **분석 깊이 선택:** 목적·사용자·맥락을 파악한 뒤 아래 **기본/장면 추가/판단 보류** 중 적절한 수준을 선택. 타이포·색·형태·정보 위계 등의 기본 관찰에서 시작하되, 모든 자료에 빛·카메라·공간 분석을 강제하지 않는다.
4. **근거 분리:** [USER] 사용자가 직접 평가, [OBS] 실제 관찰, [SOURCE] 출처의 주장, [OFFICIAL] 공식 확인, [AI-HYP] 추론, [NOT RUN] 미검증.
5. **기록/색인:** 적절한 아틀라스 문서 작성 또는 증보, [통합 허브](ATLAS_HOME.md) 및 [기존 레퍼런스 목록](README.md)에서 찾을 수 있게 연결. 실험 결과를 지어내지 않음.
6. **커밋/확인:** 텍스트 자료만 업로드한 뒤 GitHub 파일 존재와 링크·변경 범위를 확인. 이미지/폰트/원저작 강의 PDF 원본은 게시하지 않음.

## 분석 깊이 선택 — 장면 전체의 조형을 언제 볼 것인가 (2026-11-20)

**핵심 질문:** 물체·서체 하나만 살펴봐도 이미지의 매력을 충분히 설명할 수 있는가, 아니면 **구성요소 사이의 관계**(배치·빛·공간·재료·시선)가 미감을 좌우하는가? **복잡한 화면이라서 심층, 단순한 화면이라서 기본**으로 자동 분류하지 않는다.

### 장면 분석에서 사용하는 선택형 질문 (해당할 때만)

- **무엇이 주인공인가?** 시각적 무게중심과 시선의 시작·도착점은 어디인가?
- **왜 이렇게 배치된 듯한가?** 피사체의 크기·간격·비대칭·대각선·시점·원근은 무엇을 돋보이게 하는가?
- **빛과 그림자가 무슨 역할을 하는가?** 광원 방향/확산, 명도 대비, 형태를 만드는 그림자, 강조·숨김의 관계는 무엇인가?
- **배경과 재료의 역할은?** 나무·종이·금속·패브릭 등 표면의 결, 색의 상호작용, 생활감·긴장감·안정감은 어떻게 달라지는가?
- **요소들이 어떻게 함께 작동하는가?** 반복과 리듬, 곡선과 직선, 겹침과 투명도, 여백/밀도·타이포/오브젝트 관계는?
- **어떻게 다른 매체에 전이할까?** 본래 장면의 원리를 웹/UI/인쇄물에 옮길 때 유용한 점과 과장·접근성·기능적 부작용은?

**인과·의도 단정 금지:** '사진에서 보이는 것'은 **[OBS]**, '왜 그렇게 연출했을지·감정이 어떻게 생기는지'는 **[AI-HYP]**로 기록. 제작자가 밝혔다면 별도 **[SOURCE]**. 실제 렌즈·조명 설정·촬영 목적·재료 마감·작업 의도는 이미지 한 장으로 확정하지 않는다. **사용자 감상**과 AI 감상 역시 구분한다.

**분석의 비용 제한:** 모든 질문에 답할 필요가 없고, 가장 중요한 **2~4개의 관계**만 깊게 설명해도 충분하다. 비교 실험·새 시안·코드 구현은 별도 요청 또는 검증 필요가 있을 때만 한다. 이 수준 선택은 **레퍼런스 분석 운영 기준**이며, 범용 승인 지침 v1.3의 필수 규칙을 추가하는 것이 아니다.

## 등록 시 사용하는 작은 카드

|---|---|
| 자료 | ID·수집 날짜·출처·원본 링크 확인 수준 |
| 관찰 | 보이는 타이포/색/형태/질감/레이아웃/정보구조 |

| 위험 | 가독성·접근성·기능·오류·매체·저작권/라이선스 |
| 연결 | 기존 사례 및 FOUND/Pattern/Style과 연결 |
| 검증 | 정적 문서·브라우저·사용자 실험·전문 검증 중 무엇을 실제 수행했나 |

## 강의·학술 자료일 때

- 문헌의 원 주장과 슬라이드·페이지를 먼저 정확하게 기록하고, 외부 근거는 **별도 열**에 기록한다.
- 교수 직함·출판기관만으로 개별 통계·효과 크기가 검증되었다고 하지 않는다.
- 공식 표준 소개 페이지를 읽었다면 **전문 전체를 검증한 것으로 표시하지 않는다**.
- 수치·심리학 법칙의 오용 위험은 [주장 검증 레지스터](foundations/CLAIM_VERIFICATION_REGISTER.md) 형식으로 따로 보존.
- 가능한 APA 제7판 참고문헌을 사용하되, 공개되지 않은 강의 PDF는 출처 URL을 지어내지 않는다.

## 실험은 선택적 후속

레퍼런스 등록은 **정적 분석 자체로 완료 가능**. 고위험 기능/안전 문제, 상충하는 실무 가설 또는 실제 사용자 선택을 확인해야 할 때만 최소 실험을 계획한다. 미수행은 NOT RUN. 사용자 승인 없이 범용 지침 개정·웹앱 수정·배포 금지.
