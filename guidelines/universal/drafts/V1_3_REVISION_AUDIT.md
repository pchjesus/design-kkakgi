## C. 절대 잃지 말아야 할 검증 계약

- 실제 사용자·환자·의료진·법률 전문가 검증 없이 그 효과/승인을 주장하지 않기.
- 구버전 데이터/저장 키/URL·북마크가 바뀌면 마이그레이션/읽기 호환/복구/롤백을 검토하고 픽스처를 사용해 검사하기.
- 키보드, 초점 복귀, 확대/리플로우, 접근성 테스트는 관련 작업에서 계속 필수.
- 사전 검토/미확정/공식 승인/발행/완료를 정확하게 분리.
- Figma UI Kit의 전체 variants/토큰/디자인 재질을 직접 확인했다고 주장하지 않기.
- Apple/Google/외부 이미지·폰트·아이콘 원본의 Public GitHub 미승인 재배포 금지.

## G. 1~3차 비교 실험 결과 및 v1.3 최종 개정 후보 (2026-10-21)

### 자료와 범위

- **1차:** 제품/홍보, 정보/콘텐츠, 의료진 검토 도구의 A/B HTML 6개에 대한 사용자 직접 피드백. 제품형은 v1.2 선호, 콘텐츠형은 v1.3 정보 위계·동시 가시성이 강점이지만 v1.2 색채 선호, 업무형은 v1.3 색/서체/밀도 선호. 조작감 차이는 크지 않다는 평가.
- **2차 분리 실험:** 제품형 4개 피드백 — 자연광 계열 색채 B, 절제된 세리프 브랜드명 B, 넓어진 안내 패널 B(단 약 10~15% 축소 희망), 의도적 제목 줄바꿈 A 선호. 정보형 2개 — 상단 일렬 검색·필터 B, 녹색 팔레트 A 선호. 정보형 목록:상세 **1:2**는 사용자가 제안한 **이번 콘텐츠에 적합한 화면 비례의 후보**다.
- **3차 통합 피드백:** 콘텐츠 통합 B는 시각적으로 안정적·예측 가능한 위계라는 평가, 제품 통합 B 선호와 함께 **헤드라인의 브랜드명 LITO.도 로고와 같은 계열의 서체**를 쓰면 낫겠다는 구체적 제안. 독립적인 사용자 연구나 성능 측정은 아니다.
- **실험 구현 문제:** 2차 초기 HTML은 비교 옵션 선택 시 A 화면으로 돌아가 B 변경이 표시되지 않는 오류가 있었고, 이후 수정·제한된 Chromium 시험 기록이 있다. 이는 지침의 미학 실패가 아니라 **구현·비교 검증의 실패**이며 처음 자동 테스트가 누락한 경로다.

### 사용자 채택 전 남은 구분

- **PASS:** 1~3차 사용자 1인 선호 수집, 일부 실제 Chromium 조작/반응형 시험 이력, 최종 후보 문서의 내부 링크·필수 조항 점검(별도 최종 검증 참조).
