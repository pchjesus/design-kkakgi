# Universal Visual Design v1.2 — 빠른 실행 카드

> **용도:** 개발·디자인 시작 시 읽는 1페이지 가이드. 상세한 접근성·기술·안전 기준을 대체하지 않는다. 전체 지침: [Universal Visual Design & UI/UX Guidelines v1.2](Universal_Visual_Design_UI_UX_Guidelines_v1.2.md).

## 설계 시작 60초

1. **소재:** 이 콘텐츠/상품/서비스 자체의 특성은 무엇인가? 다른 업종과 뭐가 다른가?
2. **목적과 사용자:** 첫 방문자가 가장 먼저 해야 하는 행동은 무엇이며, 어떤 상황/매체에서 사용하는가?
3. **첫 화면:** `작업 우선 / 콘텐츠 우선 / 제품 우선 / 에디토리얼 / 몰입형` 중 무엇이 맞는가? **히어로·슬로건 생략도 가능.**
4. **타이포그래피:** 한글을 실제 지원하는 제목·본문 서체와 폴백을 정했는가? 영문 이탤릭·과한 자간은 의도적이며 렌더링을 확인했는가?
5. **색상:** 브랜드·소재·이용 환경이 선택 근거인가? **세이지·크림·브라운을 무의식적으로 반복하지 않는가?**
6. **카피/장식:** 설명 없는 감성 문구, 영어 overline, 거대한 원·궤도, 장식 카드가 반드시 필요한가?
7. **강점 보존:** 정보 위계, 가독성, 상태 피드백, 부드러운 목적형 모션은 유지하고 있는가?

## 규모별 적용

| 변경 종류 | 적용 범위 |
|---|---|
| **L: 문구·간격·작은 장식** | 해당 항목의 목적·가독성·실제 렌더링과 인접 영역만 점검 |
| **M: UI 구조·검색·화면 전환** | 첫 화면과 경로·상태·접근성·모바일·영향받는 회귀 테스트 |
| **H: 저장·데이터·핵심 상태·안전** | 기존 계약·호환성·마이그레이션·복구·전체 영향·승인·증거 기록 |

## 결과 리뷰 — 미관과 적합성 분리

- **미관:** 정렬·비례·타이포그래피·대비·움직임이 완성됐는가?
- **적합성:** 다른 분야의 사이트 이름만 바꾼 것처럼 보이지 않는가? 사용 목적에 바로 진입할 수 있는가?
- **정직성:** 임의 생성 정보·미확정 상태·성공하지 않은 저장을 성공처럼 보여주지 않는가?
- **검증:** 실제로 실행한 검사는 PASS/FAIL, 미실행은 NOT RUN, 비해당은 N/A로 기록한다.

**검증 방법 권장:** 제품/홍보형 + 정보/콘텐츠형 + 작업/도구형의 서로 다른 사례를 동일 조건에서 비교한다. 새 버전이 항상 더 좋게 보이도록 내용·기능·조건을 바꾸지 않는다.

**우선순위:** 프로젝트별 승인된 안전·데이터·UX 계약 및 B+ 개발 절차 > 범용 v1.2의 스타일 권고. 본 카드는 기존 구현 변경을 승인하지 않는다.
